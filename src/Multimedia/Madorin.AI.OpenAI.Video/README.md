# OpenAI Video CLI

技能名为 `skill-openai-video`，实现 OpenAI `/videos` 异步视频协议：文生视频、单张本地参考图生视频、提交、查询/等待及下载。公共契约以设计方案为准。

| 目录 | 职责 |
| --- | --- |
| Cli/ | 调度、试运行和统一终态；不包含 HTTP 或媒体解码。 |
| Requests/ | 文件/argv 合并、校验、转换、附件与任务上下文。 |
| Provider/ | multipart 提交、查询、下载、远端状态与错误。 |
| Metadata/ | 离线协议能力、参数、Schema；模型目录通过 API 获取。 |
| skill/ | 技能说明、协议引用、公共请求 Schema、调用脚本。 |
| tools/<RID>/ | 正式发布前放置经许可核对的 ffmpeg/ffprobe；不提交临时下载二进制。 |

共享命令、文件、路径、取消、超时和产物生命周期复用 Multimedia.Core。视频下载由 ffprobe 检查实际媒体信息，再由 ffmpeg 完整解码验证；Debug 可使用 PATH 中工具，Release 只允许使用随技能包打包的工具。正式发布要求每个目标 RID 提供经许可核对的 ffmpeg、ffprobe 和 `LICENSE.txt`；仓库目前不携带这些第三方二进制，因此发布会明确失败，不能以系统工具代替。

官方 SDK 已将 Sora API 标记弃用，注明计划于 2026-09-24 关闭；本项目实现协议，不承诺官方线上服务可用。兼容服务使用 --api-url；模型必须显式提供或在请求文件指定，不设模型白名单、默认模型或名称前缀限制。

不支持多参考图、尾帧、remix、编辑、远端取消与批量视频。未知普通生成参数按契约过滤；任务、模型、上下文及已支持参数的非法值失败。公开异步恢复必须保存完整 task_context；该文件不含地址、密钥、提示词或附件内容。远端取消状态如服务返回则报告，不代表 CLI 曾收到取消信号。

本批仅开发与离线验证，不正式发布、不付费生成、不提交推送。
