# 图片视频协议推进记录

本目录记录本批及后续图片、视频 Provider 协议的实现范围、官方核对、未测试内容和统一测试安排。

## 记录规则

- 每个协议单独建立一份记录，记录实际源码路径、官方端点、认证、请求/响应字段、实现边界和待办。
- 用户要求在全部协议处理完成后统一测试；协议实现阶段不运行构建、单元测试、集成测试或发布脚本。
- 未测试不等于已通过；记录必须区分源码落盘、文档核对、离线推演、假 Provider 验证和真实 API 验证。
- 发现官方协议与历史调研冲突时，以现行官方文档为准，并在对应记录中标记旧资料失效字段。

## 统一测试门禁

所有协议源码处理完成后，统一执行：

- 受影响项目构建及分析器构建。
- 文件/argv 合并、模型选择、严格 JSON、路径授权和脱敏回显。
- Provider 请求映射、模型目录、成功响应、错误响应、损坏媒体和文件冲突。
- try-run 无网络/媒体读取/文件写入副作用。
- 异步协议的提交、上下文恢复、查询、下载、超时、取消和唯一终态。
- 发布清单、资源包结构、脚本透传和允许 RID 检查。
- 真实 API、AOT、跨平台和正式发布分别记录，不能用离线证据替代。
