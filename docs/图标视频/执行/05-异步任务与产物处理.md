## 3. 异步生命周期

| 阶段 | 处理 | 响应边界 |
| --- | --- | --- |
| 提交 | 发送一次生成请求，解析任务 ID 和完整恢复状态，交宿主保存。 | 成功 submitted 带 task_context；未取得 ID 且受理未知不自动重提。未完成恢复则只内部等待，不公开 no-wait。 |
| 查询 | 同技能/端点/凭证、任务 ID 及按声明必需的上下文；单次或在本次总时限内轮询。 | 每次使用新调用 ID；返回完整最新上下文；追踪 ID 不能代任务 ID，不把 query 成功写成已下载。 |
| 远端终态 | 映射成功、部分、失败或取消。 | `TaskResponse` 保存远端状态及任务追踪；部分不表示本地存在文件。 |
| 下载 | 仅对已完成或允许部分任务取得媒体，写入临时文件后验证并原子落盘。 | `GenerateResponse` 只列完整文件；运行中为 `task_not_ready`。 |
| 清理 | 超时/取消停止正常工作，最多额外 5 秒清理和输出；仅生成等待按能力尽力取消远端，独立 query/download 不取消远端。 | remote_cancellation 记录事实，不把请求等同确认；公共失败保留已知任务、完整上下文和最后状态。 |

| 恢复与控制检查 | 实施后的最小证据 |
| --- | --- |
| 跨进程恢复 | 进程 A 提交退出，宿主只保存 task_context；进程 B 以 task-id/context-file 和 argv 凭证查询/下载，模型和原预期槽位一致。 |
| BFL URL | 使用提交返回的 polling_url，拒绝非 HTTPS、非允许主机/路径、错任务、缺失及失效状态；不在日志/错误回显 URL。 |
| stdin 生命周期 | 覆盖有效帧、错 ID、超限/非法帧、EOF、重复取消和完成竞态；无控制 ACK，只有一个终态，监听不拖住退出。 |
| 总预算 | timeout=5，媒体准备 4 秒后远端需 2 秒，应在总预算到期停止；文件更小 timeout 追溯计算，query/download 独立计时，清理不续业务。 |

## 4. 槽位与部分成功

| 规则 | 执行要求 |
| --- | --- |
| 请求 index | 调用前从 `1` 开始分配连续槽位；`num_images` 或任务定义确定预期数量。 |
| 对应关系 | 优先使用 Provider 项目 ID 或协议保证顺序；无稳定对应关系不得按完成顺序编造 index。 |
| 产物数组 | `artifacts` 按 index 升序，每槽位最多一个完整成功项。 |
| 失败数组 | `errors[].index` 与成功槽位共同覆盖预期项；不重复、不遗漏。 |
| `TaskResponse.partial` | 只描述远端已终结且部分槽位成功，不要求本地文件。 |
| `GenerateResponse.partial` | 描述部分槽位已完整落盘，其余生成或下载失败；`artifacts` 和 `errors` 均非空。 |
| 全部成功 | 所有预期槽位完整落盘返回 `success`，不因 `supports_partial=false` 改成 partial。 |
| 零成功 | 正式生成/下载没有成功产物返回公共失败；查询远端失败仍保持 `TaskResponse`。 |
