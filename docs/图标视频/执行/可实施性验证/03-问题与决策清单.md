# 问题与决策清单

[返回验证总览](./README.md) · [场景推演](./01-场景推演与预期结果.md) · [Provider 映射](./02-Provider字段映射与证据.md)

本清单记录文档级可实施性证据。设计方案为本专项最终契约依据；本清单及执行文档为其下游说明。状态“已关闭”仅表示文档决策已明确，不代表代码或平台行为已实测。

## 1. 验证结论

**整体可实施，有条件。** 设计契约已对请求、异步任务关联、恢复上下文、取消、超时和 try-run 输出边界作出决策；F01、F02、F04、F05、F06 已在文档层关闭，仍需实现后验证。跨 CLI 传同一 JSON 不保证相同功能、参数均保留或结果相同。

按下表推进：契约明确项进入实现时须遵守设计方案；Provider 能力取决于字段映射/恢复证据；`agents.md` 是临时工作约束，不作为最终验收依据。

| 结论类别 | 当前判定 | 进入实施的条件 |
| --- | --- | --- |
| 公共请求与本地处理管线 | 可原型验证 | 用假 Provider 覆盖严格 JSON、长提示词、多附件、合并、转换、丢弃和安全预检。 |
| 跨 Provider 复用 | 机制可行、语义有条件 | 每个具体任务填写字段映射表；区分原生支持/等价转换/丢弃/拒绝；调用方接受丢弃后的目标意图。 |
| 多图图片/视频 | 常见有序参考图可映射 | 每项 metadata 记录 role、顺序、数量和原生提示词位置语法；时间关键帧不冒充普通附件。 |
| 公开异步 | Provider-specific | 仅在新进程具备所需任务、路由、认证及槽位上下文时声明 `supports_async=true`。 |
| Native AOT 多 RID | 可分宿主构建和汇总 | 使用目标 OS runner/受支持环境构建；验证统一入口能调度/接收各 RID 包。RID 列表不是交叉编译保证。 |
| 真实平台/发布 | 未验证 | 后续实现后，分别提供 Native AOT 构建和目标系统实机证据。 |
