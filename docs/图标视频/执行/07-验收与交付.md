## 3. 验收矩阵

| 领域 | 最小验收内容 | 通过标准 | 证据 |
| --- | --- | --- | --- |
| 命名 | 程序、skill ID、目录、清单、YAML name、项目命名空间 | 全部按同一稳定 ID，Windows 扩展名不进入 ID | 待填写 |
| 请求 | 文件/argv、长提示词、多个附件、ID 冲突、路径边界、凭证边界 | 同一有效对象；非法协议结构失败；秘密不入文件/日志 | 待填写 |
| 模型选择 | 同文件显式切换模型、argv 覆盖文件模型、默认兜底及不支持模型/任务 | 跨 CLI 主程序显式指定模型；最终模型在有效参数与预览一致，不修改文件、不丢弃或静默回退 | 待填写 |
| 参数 | 公共和 Provider 参数、转换、过滤、Schema、默认和组合 | 可靠转换优先；非法源值/冲突/控制错误不丢弃 | 待填写 |
| try-run | 中文码点、UTF-8 往返、映射预览、verbose 双值、无副作用 | 控制值准确回显、stderr 为空；不把往返成功当乱码已排除；超时/取消用公共失败 | 待填写 |
| 响应 | 成功、失败、任务、部分成功、取消、超时 | 单 JSON、调用 ID 原样关联，任务/追踪 ID 分离，失败保留已知任务及完整上下文 | 待填写 |
| Provider | 认证、同步生成、媒体上传/引用、错误映射 | 与现行官方 API 一致；私有字段不越过 Provider 边界 | 待填写 |
| 异步恢复 | no-wait、query/wait、download、跨进程上下文、BFL polling_url | 缺失/不匹配/非法 URL 失败；模型/槽位可恢复，不确定受理不重提，不伪造本地产物 | 待填写 |
| 取消与超时 | stdin 分帧、错 ID/EOF/竞态、各阶段耗时、包装器标准流透传 | 单调总预算不重置、最多额外 5 秒清理；仅生成等待按能力远端取消，独立 query/download 不取消远端 | 待填写 |
| 发布 | 单项、全量、RID、暂存替换、锁、回滚、完整技能包 | 根 `skills/` 下每技能完整存放；失败不损坏旧包 | 待填写 |
| 平台 | Windows/Linux/macOS 目标 RID | 有实机证据才标通过；工具链缺失如实保留未验证 | 待填写 |
