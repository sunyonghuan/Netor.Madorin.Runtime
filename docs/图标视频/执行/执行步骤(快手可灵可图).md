# 快手可灵 / 可图执行步骤

日期：2026-11-10。依据 [执行计划](../策划/执行计划(快手可灵可图).md) 和 [协议记录](../协议推进记录/05-kling-image-video.md)。

协议阶段不运行构建、测试、AOT、发布或真实 API。每步完成后把实际改动写入 [执行记录](./执行记录(快手可灵可图).md)，不把计划写成已执行证据。

## S0：登记范围

- 更新协议推进索引、执行总览和 Multimedia README，标明可灵批次已开始且未测试。
- 确认不修改 Runtime、根解决方案和公共库。

验收：三处索引能定位本批计划、协议记录和执行记录。

## S1：图片项目骨架

- 创建 `Madorin.AI.Kling.Image`，引用公共库。
- 固定 `skill-kling-image`、版本 `0.1.0`、契约版本 `1.0`。
- 增加 `publish.json`、`publish.ps1` 和 `Program.cs`。入口只组合 HTTP、标准流和取消通道。

验收：项目文件与发布清单命名一致，入口没有供应商业务。

## S2：图片 metadata 与请求映射

- 声明 `metadata`、`list-models`、`generate`、`query`、`download`、`version`。
- `models` 为空。`supports_async=true`，`supports_partial=false`，查询和下载要求任务上下文。
- 实现文件与 argv 合并、模型原样传递、图片字段校验和同一映射器的 try-run。
- 拒绝参考图附件、宽高字段和未知 Provider 字段。

验收：try-run 预览使用正式映射器，不联网、不读媒体、不写文件。

## S3：图片执行与恢复

- 实现 Bearer 调用、提交、按系统任务 ID 查询、下载校验和落盘。
- 状态只认 `submitted`、`processing`、`succeed`、`failed`。
- 任务上下文不保存地址、密钥和提示词。
- `list-models` 返回 Provider 不支持。

验收：源码路径覆盖成功、失败、未就绪、超时和取消出口；不宣称已经运行。

## S4：视频项目骨架与映射

- 创建 `Madorin.AI.Kling.Video`，技能名 `skill-kling-video`。
- 声明文生视频和单图生视频。默认模型 `kling-4.0`。
- 模型放入现行路径，不改写旧端点。
- 图生视频只接受一个首帧。try-run 不读取本地图片。

验收：metadata、Schema 和请求 DTO 字段一致。

## S5：视频执行与恢复

- 提交后用 `data.id` 作为任务 ID。
- 查询 `GET /tasks?task_ids=`，只接受 `succeeded` 为成功。
- 从 `outputs` 中下载 `type=video` 的 URL，不下载水印地址。
- 支持 `query`、`query --wait`、`download` 和 `no-wait`。远端取消保持不支持。

验收：上下文可重建查询路径，失败保留已知任务 ID。

## S6：技能源文件与记录收口

- 写入两个技能的 `SKILL.md`、请求 Schema、协议引用、第三方声明和调用脚本。
- 更新 README、协议记录状态和执行记录。
- 写明未运行构建、测试、AOT、发布和真实 API。

验收：技能源文件不含密钥、媒体和本机绝对路径；根 `skills/` 未被手工修改。
