## 3. 发布包结构

```text
skills/<skill_name>/
  SKILL.md
  references/
    request.schema.json
    <provider-or-protocol-reference>.md
  scripts/
    invoke.ps1
    invoke.sh
  runtime/<RID>/
    <skill_name>[.exe]
    <required-runtime-files>
  .multimedia-release.json
```

| 目录/文件 | 必须内容 | 禁止内容 |
| --- | --- | --- |
| `SKILL.md` | 真实名称、描述、触发场景、能力、命令和用法。 | 未替换模板、未实现能力、密钥、绝对本机路径。 |
| `references/` | 请求 Schema、模型/协议字段、参数限制、异步上下文、stdin 取消、总预算和错误说明。 | 过期内容未标注、凭证、实际任务上下文或真实签名 URL。 |
| `scripts/` | invoke.ps1、invoke.sh 和必要辅助脚本；按宿主 RID 定位 CLI，透传 argv、标准流及退出码。 | 吞掉 stdin 取消帧、插入 stdout 日志、运行文件、凭证配置、生成媒体。 |
| `runtime/<RID>/` | CLI 及它的运行依赖。 | 其他 RID 文件混放、调试符号或临时输出。 |
| `.multimedia-release.json` | 技能版本、契约版本、源码修订、共享文件摘要和实际 RID。 | 把计划平台写作实际 RID，或者写入密钥。 |

## 4. 统一发布命令契约

| 操作 | 命令 | 预期行为 |
| --- | --- | --- |
| 列表 | `./publish.ps1 list` | 列出项目名、技能名、支持 RID 和单项命令，不构建。 |
| 单项 | `./publish.ps1 publish <项目名或技能名> -Rid <RID>` | 预检、调用项目脚本、暂存、校验并替换一个完整技能。 |
| 全量 | `./publish.ps1 all -Rid <RID>` | 先预检全部登记项目，再逐项发布；任一开始前不满足支持条件则失败。 |
| 平台 | `./publish.ps1 platforms` | 列出允许 RID 和当前宿主；不传 RID 时按宿主选择只是默认，不是跨平台保证。 |
| Windows 包装 | `publish.cmd ...` | 转发到 PowerShell 入口并保留退出码。 |
| Unix 包装 | `bash publish.sh ...` | 依赖 `pwsh`；明确不存在时的错误，不伪装为发布成功。 |

允许 RID：`win-x64`、`win-arm64`、`linux-x64`、`linux-arm64`、`osx-x64`、`osx-arm64`。实际交叉编译须同时满足 SDK、C/C++/原生依赖及项目配置；选择 RID 只表示请求目标。

## 5. 版本和安全替换

| 情况 | 处理 |
| --- | --- |
| 同版本新增 RID | 旧包记录存在且技能版本、契约版本、源码修订、共享文件摘要均一致，才能暂存后合并；失败保留旧包。 |
| 新版本 | 暂存本次完整包后整体替换；不得沿用上一版本 RID 冒充新版本，未发布平台可缺失。 |
| 记录缺失/未知/不一致 | 拒绝覆盖，提示需要完整新包；不默认保留旧二进制。 |
| 非本流程同名技能 | 拒绝覆盖；不能通过删除根 `skills/` 绕过。 |
| 并发发布 | 独占文件锁串行化或直接拒绝；不允许两个发布进程同时替换同一技能。 |
| 敏感材料 | 清单、日志、包、运行文件均不得包含密钥、账号、真实媒体、签名 URL 或本机绝对路径。 |
