## 3. 命令实现边界

| 命令 | 本阶段实现 | 认证 / 副作用 |
| --- | --- | --- |
| `metadata` | 返回技能、命令、认证、顶层协议 tasks、model_discovery、参数和内嵌 request_schema / task_context_schema 对象；公共请求 Schema 另随 references 文件发布。 | 不要求认证；不联网、不读媒体、不写文件，不能只返回 Schema 路径或 ID。 |
| `list-models` | 使用当前 API 地址与认证查询真实模型目录；未知任务信息为 null。 | 联网、受 timeout/取消控制；失败不回退静态清单，不按模型名称过滤；不提交生成或写媒体。 |
| `version` | 返回 CLI 版本、契约版本、Provider、能力和 runtime。 | 不要求认证。 |
| `generate --try-run` | 走完整 P2 + Provider 映射预览。 | 按声明检查凭证是否提供，不验证远端；无网络/文件副作用。 |
| `generate` | 仅建立调用接口和响应骨架，实际提交由 P4。 | 生成阶段按 metadata 需要认证；P3 不发送请求。 |
| `query` | 定义任务 ID、可选/必需上下文输入及完整任务响应，实际远端轮询由 P5。 | 不读生成请求文件，可读受限任务上下文，不下载媒体。 |
| `download` | 定义任务 ID/上下文及产物响应，实际落盘由 P5。 | 输出与上下文路径由 P2 预检，P3 不写产物。 |

## 4. Try-run 回显要求

| 字段 | 实施要求 |
| --- | --- |
| `response_id` | 已取得合法 ID 时原样回传；无合法 ID 才为 null，不能生成替代 ID。 |
| `input_parameters` | 回显合并后实际显式输入，不混入默认；保留已被转换使用的安全源字段。 |
| `effective_parameters` | 回显转换目标和确定性默认；不回显被覆盖或真正丢弃项，不猜服务端默认。 |
| `model` | 顶层模型、effective_parameters.model 和 Provider 映射采用同一最终模型；显式 argv/文件模型在 input_parameters.model 回显，默认值只入有效参数。覆盖后的旧模型不回显，无效模型或任务不兼容返回 invalid，不静默回退。 |
| `execution.verbose` | 显式输入写入 input_parameters，最终值写入 effective_parameters；允许开关改变回显，不改变 Provider 生成请求。try-run 始终不写 stderr 诊断。 |
| `request_preview` | 使用正式 Provider 映射器产生；只展示不含 HTTP header、凭证、签名和秘密的结构。 |
| `unicode_checks` | 遍历非秘密字符串，给出 JSON Pointer、显示值、Unicode Scalar Value 码点和 UTF-8 往返结果。 |
| `errors` | 字段级稳定错误码和安全说明；语法错误可含行列，不含原始秘密片段或完整绝对路径。 |
| `credential_presence` | 仅布尔表示凭证是否提供，不输出值、长度、摘要或码点。 |
| `side_effects` | 明确 `network_request=false`、`output_files_written=false`、`directories_created=false`。 |

## 5. 输出与异常规则

| 场景 | 响应 / 退出码 |
| --- | --- |
| try-run 通过 | `TryRunResponse.status=validated`，退出 `0`。 |
| try-run 参数失败 | `TryRunResponse.status=invalid`，退出 `1`；保留有效 ID。 |
| 未预期 try-run 异常 | 公共失败 `internal_error`，退出 `125`；仍无副作用。 |
| 本次超时 / stdin 协作取消 | 包括 try-run，均公共失败 timeout/4 或 cancelled/130；不是 invalid 校验结果，不输出第二份 JSON。 |
| 正式命令失败 | 公共失败对象；按第 4 节退出码映射，不输出纯文本替代 JSON。 |
| 远端任务已知失败/取消 | P5 的 `TaskResponse` 语义；不能伪装成查询调用本身失败。 |
| 无法取得有效 ID | `response_id=null`，退出 `1`；不能扫描坏输入猜取 ID。 |
