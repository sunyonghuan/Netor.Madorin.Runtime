## 3. 工程落点与职责

| 对象 | 位置 / 规则 | 责任边界 |
| --- | --- | --- |
| 技能 CLI | `src/Multimedia/Madorin.AI.<Provider>.<Capability>/` | 能力段为 `Image`、`Video`、`ImageVideo`；程序集无扩展名文件名为对应技能 ID，不插入 `Skills` 段。 |
| CLI 入口 | 技能项目内部 | argv 解析、命令路由、调用调度、单一 JSON 输出和退出码；不直接承载供应商协议。 |
| Provider 实现 | 技能内部的明确模块，按实际复杂度拆分 | 请求映射、认证、媒体提交、远端状态及错误归一；私有字段不进入公共 DTO。 |
| 公共组件 | `src/Multimedia/` 内，确有复用时建立 | 请求/响应契约、参数管线和安全规则；不依赖具体 Provider，不建立第二套 Runtime 或账号配置系统。 |
| 技能源文件 | 技能项目的 `skill/` | P6 完整编写 `SKILL.md`、`references/`、`scripts/`；未完成占位模板不能发布。 |
| 项目发布入口 | 技能项目的 `publish.json`、`publish.ps1` | 项目能单独发布，同时受统一发布保护约束；本阶段只登记差距，具体工作在 P6。 |
| 业务验证 | `tests/` 中本批对应项目 | 使用假 Provider 和临时目录；不依赖账号、外网或真实生成媒体。 |
