## 3. 异步生命周期

| 阶段 | 处理 | 响应边界 |
| --- | --- | --- |
| 提交 | 发送一次生成请求，解析远端任务 ID。 | 成功 `TaskResponse.status=submitted`；未取得 ID 且受理未知时禁止自动重提。 |
| 查询 | 以同技能、同端点、有效凭证和任务 ID 查询；可单次或在总时限内轮询。 | 每次调用有新的 `request_id`/`response_id`；不将 query 成功写成已下载。 |
| 远端终态 | 映射成功、部分、失败或取消。 | `TaskResponse` 保存远端状态及任务追踪；部分不表示本地存在文件。 |
| 下载 | 仅对已完成或允许部分任务取得媒体，写入临时文件后验证并原子落盘。 | `GenerateResponse` 只列完整文件；运行中为 `task_not_ready`。 |
| 清理 | 超时/取消时停止轮询和下载，清理未完成临时文件，按能力尝试远端取消。 | `remote_cancellation` 记录 requested/confirmed/failed/unknown 等事实，不把请求等同确认。 |

## 4. 槽位与部分成功

| 规则 | 执行要求 |
| --- | --- |
| 请求 index | 调用前从 `1` 开始分配连续槽位；`num_images` 或任务定义确定预期数量。 |
| 对应关系 | 优先使用 Provider 项目 ID 或协议保证顺序；无稳定对应关系不得按完成顺序编造 index。 |
| 产物数组 | `artifacts` 按 index 升序，每槽位最多一个完整成功项。 |
| 失败数组 | `errors[].index` 与成功槽位共同覆盖预期项；不重复、不遗漏。 |
| `TaskResponse.partial` | 只描述远端已终结且部分槽位成功，不要求本地文件。 |
| `GenerateResponse.partial` | 描述部分槽位已完整落盘，其余生成或下载失败；`artifacts` 和 `errors` 均非空。 |
| 全部成功 | 所有预期槽位完整落盘返回 `success`，不因 `supports_partial=false` 改成 partial。 |
| 零成功 | 正式生成/下载没有成功产物返回公共失败；查询远端失败仍保持 `TaskResponse`。 |
