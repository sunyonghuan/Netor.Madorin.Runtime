## 3. Provider 模块边界

| 层 | 责任 | 禁止事项 |
| --- | --- | --- |
| CLI 入口 | 接收 argv、调用公共输入管线、选择 Provider、输出公共 JSON。 | 不拼接 Shell 命令，不解析供应商私有响应，不把私有字段塞进公共根 DTO。 |
| Provider 适配器 | 地址和认证映射、请求 DTO、HTTP 调用、供应商状态/错误转换。 | 不把 API Key 写入请求文件、metadata 默认值、stderr 或 `request_preview`。 |
| 媒体处理 | 按供应商协议上传、引用或编码；返回安全的远端媒体/任务信息。 | 不把本机路径作为服务端可访问地址；不在日志中输出签名 URL。 |
| 公共映射 | 统一提示词、附件角色、尺寸、时长、数量和结果字段。 | 不能只因字段名称不同丢弃；没有可靠语义时才记录 `ignored_parameters`。 |
| 供应商私有字段 | `/provider_parameters/<provider>/...` 及实际 Provider 请求 DTO。 | 不跨 Provider 透传原始字段；不增加未在方案中定义的公共根字段。 |
