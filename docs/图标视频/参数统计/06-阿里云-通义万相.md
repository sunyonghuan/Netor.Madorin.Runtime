# 阿里云通义万相 API (图片生成)

## 基本信息

- **厂商**: 阿里云 DashScope
- **产品**: 通义万相 (Wanxiang)
- **基础域名**: `https://dashscope.aliyuncs.com`
- **文档**: https://help.aliyun.com/zh/model-studio/wan-image-generation-api-reference
- **控制台**: https://dashscope.console.aliyun.com/

## 认证

```
Authorization: Bearer YOUR_DASHSCOPE_API_KEY
X-DashScope-Async: enable  (可选，用于异步任务)
```

## 主要端点

### 1. 文生图 (Text-to-Image)

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis
```

### 2. 图像编辑 (Image Editing)

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image2image/image-editing
```

### 3. 局部重绘 (Inpainting)

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image2image/inpainting
```

### 4. 涂鸦作画 (Sketch-to-Image)

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/sketch2image/sketch-to-image
```

## 文生图 API 详细参数

### 请求参数

| 参数路径 | 类型 | 必需 | 说明 | 默认值 |
|---------|------|------|------|--------|
| `model` | string | ✅ | 模型名称 | - |
| `input.prompt` | string | ✅ | 正向提示词 | - |
| `input.negative_prompt` | string | ❌ | 负向提示词 | - |
| `parameters.style` | string | ❌ | 风格预设 | `<auto>` |
| `parameters.size` | string | ❌ | 图片尺寸 | `1024*1024` |
| `parameters.n` | integer | ❌ | 生成数量 (1-4) | 1 |
| `parameters.seed` | integer | ❌ | 随机种子 | 随机 |
| `parameters.ref_img` | string | ❌ | 参考图 URL | - |
| `parameters.ref_strength` | float | ❌ | 参考图强度 (0.0-1.0) | 0.5 |

### 支持的模型

| 模型名称 | 说明 |
|---------|------|
| `wanx-v1` | 通义万相 v1 基础模型 |
| `wanx-lite-v1` | 轻量快速版本 |
| `wanx-sketch-to-image-v1` | 涂鸦转图片 |
| `wanx-background-generation-v2` | 背景生成 |
| `wanx-style-repaint-v1` | 风格重绘 |

### 支持的尺寸

- `1024*1024` (1:1)
- `720*1280` (9:16)
- `1280*720` (16:9)
- `768*1024` (3:4)
- `1024*768` (4:3)

### 支持的风格

| 风格值 | 说明 |
|--------|------|
| `<auto>` | 自动 |
| `<3d cartoon>` | 3D 卡通 |
| `<anime>` | 动漫 |
| `<oil painting>` | 油画 |
| `<watercolor>` | 水彩 |
| `<sketch>` | 素描 |
| `<chinese painting>` | 国画 |
| `<flat illustration>` | 扁平插画 |
| `<photography>` | 摄影 |
| `<realistic>` | 写实 |

### 请求示例

```json
{
  "model": "wanx-v1",
  "input": {
    "prompt": "一只可爱的小猫在花园里玩耍,阳光明媚",
    "negative_prompt": "模糊,低质量,扭曲"
  },
  "parameters": {
    "style": "<photography>",
    "size": "1024*1024",
    "n": 2,
    "seed": 42,
    "ref_strength": 0.5
  }
}
```

### 异步响应

启用异步时（Header: `X-DashScope-Async: enable`）：

```json
{
  "request_id": "fb...",
  "output": {
    "task_id": "abc123",
    "task_status": "PENDING"
  }
}
```

查询任务状态：

```
GET https://dashscope.aliyuncs.com/api/v1/tasks/{task_id}
Authorization: Bearer YOUR_API_KEY
```

## 图像编辑 API

### 端点

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image2image/image-editing
```

### 特有参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `input.image_url` | string | ✅ | 输入图片 URL |
| `input.prompt` | string | ✅ | 编辑指令 |
| `parameters.editing_strength` | float | ❌ | 编辑强度 (0.0-1.0) |

### 请求示例

```json
{
  "model": "wanx-v1",
  "input": {
    "image_url": "https://example.com/input.jpg",
    "prompt": "将背景改为海滩"
  },
  "parameters": {
    "editing_strength": 0.7
  }
}
```

## 局部重绘 API

### 端点

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image2image/inpainting
```

### 特有参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `input.image_url` | string | ✅ | 输入图片 URL |
| `input.mask_url` | string | ✅ | 蒙版图片 URL (白色区域为重绘区域) |
| `input.prompt` | string | ✅ | 重绘内容描述 |

```json
{
  "model": "wanx-v1",
  "input": {
    "image_url": "https://example.com/input.jpg",
    "mask_url": "https://example.com/mask.png",
    "prompt": "一只蝴蝶"
  }
}
```

## 参数结构差异

### OpenAI 风格

```json
{
  "model": "dall-e-3",
  "prompt": "...",
  "size": "1024x1024",
  "quality": "hd",
  "n": 1
}
```

### 阿里云风格

```json
{
  "model": "wanx-v1",
  "input": {
    "prompt": "...",
    "negative_prompt": "..."
  },
  "parameters": {
    "size": "1024*1024",
    "style": "<auto>",
    "n": 1,
    "seed": 42
  }
}
```

**关键差异**：
- ❌ **参数嵌套**: 使用 `input` 和 `parameters` 嵌套结构
- ❌ **尺寸格式**: `1024*1024` 而非 `1024x1024`
- ❌ **响应结构**: 使用 `output.results[].url` 而非 `data[].url`
- ❌ **认证方式**: 相同 (Bearer Token)

## 最佳实践

1. **中文提示词**: 使用中文描述效果最佳
2. **负面提示词**: 添加"模糊,低质量,扭曲"等排除常见问题
3. **固定种子**: 需要复现时使用相同 seed
4. **风格选择**: 明确使用场景选择合适风格（摄影、动漫、国画等）
5. **异步模式**: 批量生成时使用异步模式避免超时
6. **图片下载**: 生成后 24 小时内下载并保存
7. **尺寸选择**: 使用 `*` 而非 `x` 分隔尺寸
8. **参考图片**: 使用 `ref_img` 和 `ref_strength` 进行风格迁移
9. **错误处理**: 捕获内容审核错误（ContentReview.Blocked）
10. **多端点**: 根据需求选择专用端点（编辑/重绘/涂鸦）
