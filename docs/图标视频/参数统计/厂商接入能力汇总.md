## 三、已有 CLI 的厂商特性对比

### 火山方舟 Ark CLI

**产品**: Seedream (图片) + Seedance (视频)

**CLI 特点**:
- ✅ AI 原生 CLI,专为生成式 AI 设计
- ✅ 支持 MCP Server 模式
- ✅ 本地安装、命令行调用
- ✅ 异步任务管理
- ✅ 已列入 mcli_process allowlist 需求

**API 端点**:
- 图片: 火山引擎方舟平台 API v3
- 视频: Seedance 2.0/2.5 异步任务

**认证**: `ARK_API_KEY`

**接入方案**: 
- ✅ **已有技能模式 CLI,无需重复开发**
- 可直接集成到 Runtime

### 阿里云 CLI

**产品**: 通义万相 (Wanxiang)

**CLI 调用**:
```bash
aliyun dashscope POST /api/v1/services/aigc/text2image/image-synthesis
```

**特点**:
- ✅ 通用云 CLI,覆盖所有阿里云服务
- ❌ 非 AI 原生,需手工构造 JSON 参数
- ✅ Bearer Token 认证

**接入方案**: 
- 封装为技能 CLI
- 内部调用 `aliyun` 命令

### 腾讯云 CLI

**产品**: 混元图像 + HunyuanVideo

**CLI 调用**:
```bash
tccli hunyuan TextToImage --Prompt "..."
```

**特点**:
- ✅ 通用云 CLI
- ❌ TC3 签名机制复杂
- ❌ 需要 SecretId + SecretKey

**接入方案**: 
- 封装为技能 CLI
- 内部处理 TC3 签名

### 百度云 CLI

**产品**: 文心一格 + 视频生成

**CLI 调用**:
```bash
bce qianfan image generate --prompt "..."
```

**特点**:
- ✅ 通用云 CLI
- ❌ 非 AI 原生

**接入方案**: 
- 封装为技能 CLI
- 内部调用 `bce` 命令

## 六、MCP Server 接入路径

除了技能 CLI,部分厂商可通过 MCP Server 方式接入:

### 官方 MCP Server

- ✅ **火山方舟** - 官方提供

### 社区 MCP Server

- 智谱 AI (社区实现)
- OpenAI (社区实现)
- Stability AI (社区实现)

**MCP Server 优势**:
- 更贴近"以技能模式安装到本地"
- Agent 可直接调用
- 参数校验由 MCP 协议统一

**MCP Server 劣势**:
- 需要 MCP 运行时
- 社区实现质量参差不齐

## 七、结论与建议

### 核心结论

1. **真正的 AI 原生 CLI 只有火山方舟 Ark CLI**
   - 已有技能模式 CLI,无需重复开发
   - 应优先完成 mcli_process allowlist 注册

2. **云厂商通用 CLI 可复用但需封装**
   - 阿里云 `aliyun`
   - 腾讯云 `tccli`
   - 百度云 `bce`

3. **其余厂商需自建技能 CLI**
   - 快手、智谱、MiniMax、xAI、Stability AI、BFL 等
   - 按 HTTP API 封装为统一技能契约

### 技能契约设计原则

基于已收集的厂商参数,技能契约应包含:

1. **核心参数** (100% 覆盖)
   - `prompt`
   - `model`
   - 尺寸控制 (size / aspect_ratio / width+height)

2. **高频参数** (50%+ 覆盖)
   - `num_images` (批量生成)
   - `response_format` (url / base64)

3. **专业参数** (可选,按需映射)
   - `negative_prompt` (负面提示词)
   - `seed` (随机种子)
   - `reference_images` (参考图片)
   - `guidance_scale` (引导强度)
   - `steps` (推理步数)

4. **视频特有参数**
   - `duration` (时长)
   - `resolution` (分辨率)
   - `fps` (帧率)
   - `image_url` (图生视频输入)

详细参数设计见 `00-公共参数汇总.md`。
