# 腾讯云混元生图 API

## 基本信息

- **厂商**: 腾讯云
- **产品**: 混元生图 (Hunyuan Image)
- **文档**: https://cloud.tencent.com/document/product/1729/105969
- **API 规范**: 腾讯云 API 3.0

## 认证

腾讯云 API 3.0 签名认证（需要 SecretId 和 SecretKey）

```
Authorization: TC3-HMAC-SHA256 Credential=...
X-TC-Action: ImageToImage (或其他 Action)
X-TC-Version: 2023-09-01
X-TC-Timestamp: 1234567890
X-TC-Region: ap-guangzhou
```

## 主要端点

### 极速版 (Turbo)

```
POST https://aiart.tencentcloudapi.com
Action: TextToImage
```

### 轻量版 (Lite)

```
POST https://hunyuan.tencentcloudapi.com
Action: TextToImage
```

### 标准版 (Standard)

**提交任务**:
```
POST https://hunyuan.tencentcloudapi.com
Action: SubmitTextToImageJob
```

**查询任务**:
```
POST https://hunyuan.tencentcloudapi.com
Action: QueryTextToImageJob
```

## 极速版 API (实时同步)

### Action

```
TextToImage
```

### 请求参数

| 参数 | 类型 | 必需 | 说明 | 默认值 |
|------|------|------|------|--------|
| `Prompt` | string | ✅ | 正向提示词 (最多 1024 字符) | - |
| `NegativePrompt` | string | ❌ | 负向提示词 | - |
| `Style` | string | ❌ | 风格预设 (201-220) | - |
| `Resolution` | string | ❌ | 分辨率 | `1:1` |
| `Num` | integer | ❌ | 生成数量 (1-4) | 1 |
| `Seed` | integer | ❌ | 随机种子 | 随机 |
| `LogoAdd` | integer | ❌ | 是否添加水印 (0/1) | 0 |
| `RspImgType` | string | ❌ | 返回图片类型 | `url` |

### 支持的风格

| 风格代码 | 说明 |
|---------|------|
| `201` | 通用 |
| `202` | 国风 |
| `203` | 写实 |
| `204` | 油画 |
| `205` | 水彩 |

| `FailedOperation.ImageDecodeFailed` | 图片解码失败 |
| `FailedOperation.InsufficientBalance` | 余额不足 |
| `FailedOperation.RequestEntityTooLarge` | 请求体过大 |
| `LimitExceeded.JobNumExceeded` | 任务数量超限 |
| `ResourceNotFound.JobNotExist` | 任务不存在 |
| `UnsupportedOperation.ContentCheck` | 内容审核不通过 |

## 参数结构差异

### OpenAI 风格

```json
{
  "model": "dall-e-3",
  "prompt": "...",
  "size": "1024x1024"
}
```

### 腾讯云风格

```json
{
  "Action": "TextToImage",
  "Version": "2023-09-01",
  "Region": "ap-guangzhou",
  "Prompt": "...",
  "Resolution": "1:1",
  "Style": "201"
}
```

**关键差异**：
- ❌ **Action 驱动**: 使用 `Action` 参数而非 URL 路径区分功能
- ❌ **Version + Region**: 必须指定 API 版本和地域
- ❌ **签名认证**: TC3-HMAC-SHA256 签名，非简单 Bearer Token
- ❌ **参数命名**: 首字母大写（`Prompt` 而非 `prompt`）
- ❌ **响应嵌套**: 使用 `Response` 包装
- ❌ **风格编码**: 数字代码（201）而非字符串（`<photography>`）

## 最佳实践

1. **版本选择**
   - 快速测试 → 极速版
   - 平衡场景 → 轻量版
   - 高质量需求 → 标准版

2. **签名生成**: 使用腾讯云官方 SDK 生成签名，避免手工计算

3. **中文提示词**: 使用中文描述效果最佳

4. **负面提示词**: 添加"模糊,低质量,扭曲"等

5. **异步轮询**: 标准版建议每 3-5 秒轮询一次

6. **水印控制**: 商业使用时设置 `LogoAdd=0` 去除水印（需计费）

7. **种子复现**: 使用相同 `Seed` 复现结果

8. **地域选择**: `ap-guangzhou`（广州）或 `ap-beijing`（北京）延迟较低

9. **错误处理**: 捕获 `UnsupportedOperation.ContentCheck` 内容审核错误

10. **批量生成**: 极速版/轻量版支持 `Num=1-4` 批量生成

## SDK 示例

### Python (使用腾讯云 SDK)

```python
from tencentcloud.common import credential
from tencentcloud.hunyuan.v20230901 import hunyuan_client, models

cred = credential.Credential("SecretId", "SecretKey")
client = hunyuan_client.HunyuanClient(cred, "ap-guangzhou")

req = models.TextToImageRequest()
req.Prompt = "一只可爱的熊猫"
req.Style = "201"
req.Resolution = "1:1"
req.Num = 1

resp = client.TextToImage(req)
print(resp.ResultImage)
```

## 迁移注意事项

从 OpenAI 迁移至腾讯云混元时：

1. **认证方式**: Bearer Token → TC3 签名
2. **参数大小写**: 小写 → 首字母大写
3. **响应结构**: `data[]` → `Response.ResultDetails[]`
4. **端点结构**: RESTful 路径 → Action 参数
5. **异步任务**: 实现提交 + 轮询逻辑（标准版）
6. **地域参数**: 增加 `Region` 参数
7. **风格编码**: 字符串 → 数字代码
