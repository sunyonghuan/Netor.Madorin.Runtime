## 视频生成 API (可灵 Kling)

### 模型版本

| 模型 | 说明 | 特点 |
|------|------|------|
| `kling-3.0-omni` | 全能视频生成 | 最新版本，全能力支持 |
| `kling-pro` | 专业版 | 高质量 |
| `kling-standard` | 标准版 | 平衡质量与成本 |

### 质量等级

- **Standard**: 标准质量
- **Pro**: 专业质量
- **4K**: 4K 超高清

### 核心请求参数

| 参数 | 类型 | 必需 | 说明 | 默认值 |
|------|------|------|------|--------|
| `prompt` | string | ✅ | 文本描述 | - |
| `model` | string | ❌ | 模型版本 | `kling-3.0-omni` |
| `mode` | string | ❌ | 生成模式 | `text-to-video` |
| `image_url` | string | ❌ | 输入图片 URL (图生视频) | - |
| `duration` | integer | ❌ | 视频时长（秒，5/10） | 5 |
| `quality` | string | ❌ | 质量等级 | `standard` |
| `aspect_ratio` | string | ❌ | 宽高比 | `16:9` |
| `camera_control` | object | ❌ | 摄像机控制 | - |
| `native_audio` | boolean | ❌ | 原生音频 | false |
| `multi_shot` | boolean | ❌ | 多镜头模式 | false |

### 生成模式

- `text-to-video`: 文生视频
- `image-to-video`: 图生视频
- `multi-image`: 多图参考视频

### 支持的宽高比

- `16:9` - 横屏
- `9:16` - 竖屏
- `1:1` - 正方形

### 摄像机控制参数

```json
{
  "camera_control": {
    "movement": "zoom_in",  // 摄像机运动
    "speed": "medium",      // 运动速度
    "angle": "front"        // 拍摄角度
  }
}
```

### 摄像机运动类型

- `zoom_in` - 推进
- `zoom_out` - 拉远
- `pan_left` - 左摇
- `pan_right` - 右摇
- `tilt_up` - 上仰
- `tilt_down` - 下俯
- `static` - 固定

### 请求示例

#### 文生视频

```json
{
  "model": "kling-3.0-omni",
  "mode": "text-to-video",
  "prompt": "一只小猫在草地上奔跑，阳光明媚",
  "duration": 5,
  "quality": "pro",
  "aspect_ratio": "16:9",
  "native_audio": true
}
```

#### 图生视频

```json
{
  "model": "kling-pro",
  "mode": "image-to-video",
  "prompt": "让画面动起来，人物微笑挥手",
  "image_url": "https://example.com/input.jpg",
  "duration": 10,
  "quality": "standard",
  "aspect_ratio": "9:16"
}
```

### 响应格式

**提交响应** (异步):

```json
{
  "job_id": "kling_abc123",
  "status": "pending",
  "created_at": "2026-10-20T04:00:00Z"
}
```

**查询结果**:

```
GET /api/v1/videos/{job_id}
```

**完成响应**:

```json
{
  "job_id": "kling_abc123",
  "status": "completed",
  "result": {
    "video_url": "https://...",
    "duration": 5,
    "quality": "pro",
    "aspect_ratio": "16:9",
    "has_audio": true
  },
  "completed_at": "2026-10-20T04:02:30Z"
}
```

## 图片生成 API (可图)

### 核心请求参数

| 参数 | 类型 | 必需 | 说明 | 默认值 |
|------|------|------|------|--------|
| `prompt` | string | ✅ | 文本描述 | - |
| `negative_prompt` | string | ❌ | 负面提示词 | - |
| `width` | integer | ❌ | 宽度 | 1024 |
| `height` | integer | ❌ | 高度 | 1024 |
| `num_images` | integer | ❌ | 生成数量 (1-4) | 1 |
| `style` | string | ❌ | 风格预设 | - |
| `seed` | integer | ❌ | 随机种子 | 随机 |

### 支持的尺寸

- `1024x1024` (1:1)
- `1280x720` (16:9)
- `720x1280` (9:16)
- `1024x768` (4:3)
- `768x1024` (3:4)

### 请求示例

```json
{
  "prompt": "一幅山水画，水墨风格",
  "negative_prompt": "模糊，低质量",
  "width": 1024,
  "height": 1024,
  "num_images": 2,
  "seed": 42
}
```

### 响应格式

```json
{
  "images": [
    {
      "url": "https://...",
      "seed": 42
    },
    {
      "url": "https://...",
      "seed": 43
    }
  ]
}
```

## 特殊能力

### 可灵视频独有

- ✅ **智能切镜**: 多镜头模式，自动切换场景
- ✅ **摄像机控制**: 精确控制摄像机运动
- ✅ **原生音频**: 自动生成匹配的音效
- ✅ **多镜头模式**: 支持多镜头序列生成
- ✅ **4K 输出**: 支持超高清 4K 分辨率
- ✅ **首尾帧生成**: 支持指定首尾帧的视频生成
- ✅ **角色稳定性**: 保持角色一致性

### 可图图片

- ✅ **中文优化**: 深度优化中文提示词
- ✅ **负面提示词**: 支持负面提示词
- ✅ **随机种子**: 可复现生成结果
- ✅ **自定义尺寸**: 灵活的尺寸控制

## 最佳实践

### 视频生成

1. **摄像机控制**: 使用 `camera_control` 精确控制镜头运动
2. **多镜头模式**: 复杂场景使用 `multi_shot` 实现多角度
3. **原生音频**: 需要音效时启用 `native_audio`
4. **质量选择**: 测试用 Standard，正式用 Pro，展示用 4K
5. **中文提示词**: 使用中文描述效果最佳
6. **异步轮询**: 建议 5-10 秒轮询一次状态

### 图片生成

1. **负面提示词**: 添加"模糊,低质量,扭曲"等
2. **固定种子**: 使用相同 seed 复现结果
3. **批量生成**: 使用 `num_images=2-4` 获取多个选项
4. **尺寸选择**: 根据用途选择合适宽高比
