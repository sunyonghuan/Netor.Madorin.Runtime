# 百度文心一格 API (图片生成 + 视频生成)

## 基本信息

- **厂商**: 百度
- **产品**: 文心一格 (图片), 文心视频生成
- **官网**: https://yiyan.baidu.com
- **开放平台**: 
  - 千帆平台: https://qianfan.baidubce.com
  - 百度智能云: https://console.bce.baidu.com
- **CLI**: ✅ **`bce` CLI** (百度云通用 CLI)
- **文档**: 千帆平台 API 文档

## CLI 支持

百度云提供 `bce` CLI，覆盖千帆平台服务：

```bash
bce qianfan image generate --prompt "..."
bce qianfan video generate --prompt "..."
```

**安装**: 从百度云官网下载安装包

## 认证方式

### API Key + Secret Key

```
X-Bce-Api-Key: YOUR_API_KEY
X-Bce-Secret-Key: YOUR_SECRET_KEY
```

或使用 App ID 方式：

```
X-Bce-App-Id: YOUR_APP_ID
X-Bce-Api-Key: YOUR_API_KEY
X-Bce-Secret-Key: YOUR_SECRET_KEY
```

## 图片生成 API (文心一格)

### 核心请求参数

| 参数 | 类型 | 必需 | 说明 | 默认值 |
|------|------|------|------|--------|
| `prompt` | string | ✅ | 文本描述 | - |
| `negative_prompt` | string | ❌ | 负面提示词 | - |
| `width` | integer | ❌ | 宽度 | 1024 |
| `height` | integer | ❌ | 高度 | 1024 |
| `num_images` | integer | ❌ | 生成数量 (1-4) | 1 |
| `style` | string | ❌ | 风格预设 | - |
| `seed` | integer | ❌ | 随机种子 | 随机 |

### 支持的风格

- `realistic` - 写实
- `anime` - 动漫
- `chinese_painting` - 国画
- `oil_painting` - 油画
- `watercolor` - 水彩
- `cartoon` - 卡通

### CLI 调用示例

```bash
bce qianfan image generate \
  --prompt "一幅山水画，水墨风格" \
  --negative-prompt "模糊，低质量" \
  --width 1024 \
  --height 1024 \
  --style chinese_painting \
  --num-images 2
```

### API 请求示例

```json
{
  "prompt": "一幅山水画，水墨风格，意境深远",
  "negative_prompt": "模糊，低质量，噪点",
  "width": 1024,
  "height": 1024,
  "num_images": 2,
  "style": "chinese_painting",
  "seed": 42
}
```

### 响应格式

```json
{
  "request_id": "req_abc123",
  "images": [
    {
      "url": "https://...",
      "seed": 42,
      "width": 1024,
      "height": 1024
    },
    {
      "url": "https://...",
      "seed": 43,
      "width": 1024,
      "height": 1024
    }
  ]
}
```

## 视频生成 API

### 核心请求参数

| 参数 | 类型 | 必需 | 说明 | 默认值 |
|------|------|------|------|--------|
| `prompt` | string | ✅ | 文本描述 | - |
| `image_url` | string | ❌ | 输入图片 (图生视频) | - |
| `duration` | integer | ❌ | 时长（秒，5/10） | 5 |
| `resolution` | string | ❌ | 分辨率 | `720p` |
| `aspect_ratio` | string | ❌ | 宽高比 | `16:9` |

### CLI 调用示例

```bash
bce qianfan video generate \
  --prompt "一只小猫在草地上玩耍" \
  --duration 5 \
  --resolution 720p \
  --aspect-ratio "16:9"
```

### API 请求示例

```json
{
  "prompt": "一只小猫在草地上追逐蝴蝶",
  "duration": 5,
  "resolution": "720p",
  "aspect_ratio": "16:9"
}
```

### 响应格式 (异步)

**提交响应**:
```json
{
  "task_id": "task_abc123",
  "status": "pending"
}
```

**完成响应**:
```json
{
  "task_id": "task_abc123",
  "status": "completed",
  "video_url": "https://...",
  "duration": 5,
  "resolution": "720p"
}
```

## 错误码

| 错误码 | 说明 |
|--------|------|
| 100 | 参数错误 |
| 110 | API Key 无效 |
| 111 | 余额不足 |
| 336000 | 内部错误 |
| 336001 | 请求频率超限 |
| 336002 | 内容审核不通过 |

## 最佳实践

### CLI 模式
1. **安装配置**: 下载 `bce` CLI 并配置 API Key
2. **命令封装**: 通过技能 CLI 内部调用 `bce` 命令
3. **参数映射**: 将公共参数映射到 `bce` 参数
4. **错误处理**: 解析 `bce` 输出的错误码

### API 模式
1. **中文提示词**: 使用中文描述效果最佳
2. **负面提示词**: 添加"模糊,低质量,噪点"等
3. **风格选择**: 明确场景选择合适风格
4. **固定种子**: 使用相同 seed 复现
5. **异步轮询**: 视频生成建议 5 秒轮询一次
