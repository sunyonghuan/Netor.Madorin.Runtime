# 图片/视频生成 API 公共参数汇总

## 文档说明

本文档汇总了各大厂商图片/视频生成 API 的参数，用于抽取公共参数设计技能契约。

**更新**: 已补充快手可灵、MiniMax、生数Vidu、阶跃星辰、百度文心一格等国内主流厂商。

## 公共参数分类

### 核心参数（100%覆盖）

| 参数 | 类型 | 说明 | 图片覆盖率 | 视频覆盖率 |
|------|------|------|-----------|-----------|
| `prompt` | string | 文本描述 | 100% | 100% |
| 尺寸控制 | 多种形式 | size/width+height/aspect_ratio | 100% | 100% |

### 高频参数（50%+覆盖）

| 参数 | 类型 | 说明 | 图片覆盖率 | 视频覆盖率 |
|------|------|------|-----------|-----------|
| `model` | string | 模型名称 | 85% | 89% |
| `num_images` / `n` | integer | 生成数量 | 77% | - |
| `negative_prompt` | string | 负面提示词 | 62% | - |
| `seed` | integer | 随机种子 | 62% | 11% |
| `image_url` | string | 图生视频输入 | - | 100% |
| `duration` | integer | 视频时长 | - | 100% |
| `resolution` | string | 视频分辨率 | - | 100% |

### 专业参数（部分厂商）

**图片生成**:
- `style`: 风格预设 (46%)
- `quality`: 质量等级 (38%)
- `reference_images`: 参考图片 (38%)
- `guidance_scale`: 引导强度 (15% - Replicate, BFL)
- `steps`: 推理步数 (15% - Replicate, BFL)

**视频生成**:
- `aspect_ratio`: 宽高比 (56%)
- `sound_effects`: 音效生成 (44% - xAI, 快手, MiniMax, Vidu)
- `first_frame` / `last_frame`: 首尾帧 (22% - MiniMax, Vidu)
- `camera_control`: 摄像机控制 (22% - 快手, MiniMax)
- `multi_shot`: 多镜头 (22% - 快手, MiniMax)
- `keyframe_editing`: 关键帧编辑 (11% - MiniMax)
- `fps`: 自定义帧率 (22%)

## 尺寸参数的三种模式

### 模式1: 固定尺寸枚举 (OpenAI, Azure, 智谱)

```json
{
  "size": "1024x1024"
}
```

可选值: `1024x1024`, `1792x1024`, `1024x1792`

### 模式2: 宽高比 (Stability AI, 阿里云, 腾讯云, xAI, 快手, Vidu)

```json
{
  "aspect_ratio": "16:9"
}
```

可选值: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `21:9`, etc.

### 模式3: 自由宽高 (Replicate, BFL FLUX, MiniMax, 阶跃, 百度)

```json
{
  "width": 1024,
  "height": 768
}
```

约束:
- Replicate: 128-2048
- BFL FLUX: 256-1440, 必须32倍数
- MiniMax: 256-2048
- 百度: 通用尺寸

## 公共参数设计建议

基于14个厂商的参数分析，技能契约应包含:

### 最小必需参数

```json
{
  "prompt": "string (必需)",
  "model": "string (可选，默认由技能决定)"
}
```

### 图片生成推荐参数

```json
{
  "prompt": "string",
  "negative_prompt": "string (可选)",
  "width": "integer (可选)",
  "height": "integer (可选)",
  "aspect_ratio": "string (可选，优先于width/height)",
  "num_images": "integer (可选，默认1)",
  "seed": "integer (可选)",
  "style": "string (可选)",
  "quality": "string (可选: standard/hd/ultra)",
  "output_format": "string (可选: url/base64)",
  "model": "string (可选)"
}
```

### 视频生成推荐参数

```json
{
  "prompt": "string",
  "image_url": "string (可选，图生视频)",
  "first_frame_url": "string (可选，首帧)",
  "last_frame_url": "string (可选，尾帧)",
  "duration": "integer (秒)",
  "resolution": "string (可选: 480p/720p/1080p/2K/4K)",
  "aspect_ratio": "string (可选)",
  "fps": "integer (可选，默认30)",
  "camera_control": "object (可选)",
  "keyframes": "array (可选)",
  "sound_effects": "boolean (可选)",
  "model": "string (可选)"
}
```

### 高级参数（按需映射）

```json
{
  "guidance_scale": "float (可选，Replicate/BFL)",
  "steps": "integer (可选，Replicate/BFL)",
  "reference_images": [
    {"url": "string", "weight": "float"}
  ]
}
```

## 技能内部适配策略

### 1. 参数映射

将公共参数映射到供应商特定参数:

| 公共参数 | OpenAI | 阿里云 | 腾讯云 | 快手 | MiniMax |
|---------|--------|--------|--------|------|---------|
| `num_images` | `n` | `parameters.n` | `Num` | `num_images` | `num_images` |
| `aspect_ratio` | → `size` | - | `Resolution` | `aspect_ratio` | - |
| `negative_prompt` | - | `input.negative_prompt` | `NegativePrompt` | `negative_prompt` | `negative_prompt` |

### 2. 参数验证

检查供应商是否支持该参数:
- `negative_prompt`: 仅传递给支持的厂商 (62%覆盖)
- `seed`: 忽略不支持的厂商 (OpenAI, xAI, 智谱)
- `camera_control`: 仅快手、MiniMax支持

### 3. 默认值填充

为供应商必需但用户未提供的参数填充默认值:
- 阿里云: 填充 `input` / `parameters` 嵌套结构
- 腾讯云: 填充 `Action`, `Version`, `Region`
- 百度: 填充 `app_id`

### 4. 认证适配

根据供应商转换认证方式:
- Bearer Token (77%)
- TC3签名 (腾讯云)
- X-Key (BFL)
- API Key + Secret Key (百度)

### 5. 响应规范化

将不同格式响应映射到统一格式:

**统一输出格式**:
```json
{
  "status": "completed",
  "type": "image" | "video",
  "artifacts": [
    {
      "url": "string",
      "format": "png|mp4|...",
      "width": "integer",
      "height": "integer",
      "duration": "float (视频)",
      "seed": "integer (if available)"
    }
  ],
  "provider_metadata": {
    "task_id": "string",
    "model": "string"
  }
}
```

## 错误码标准化映射

| 标准错误码 | 说明 | 映射来源 |
|-----------|------|---------|
| `invalid_parameter` | 参数错误 | 400, InvalidParameter, invalid_request |
| `authentication_failed` | 认证失败 | 401, unauthorized, authentication_error |
| `insufficient_balance` | 余额不足 | 402, InsufficientBalance, payment_required |
| `content_policy_violation` | 内容违规 | 403, ContentReview.Blocked, content_policy |
| `rate_limit_exceeded` | 速率限制 | 429, Throttling.RateQuota, rate_limit |
| `provider_error` | 供应商错误 | 500, InternalError, server_error |
