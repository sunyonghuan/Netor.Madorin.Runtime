# Work 模式文档备档

> ⚠️ **已废弃**：Work 模式在 v0.2.0 中被移除。

## 移除原因

- Runtime 重新定位为「轻量级 AI 访问协调器」
- Work 模式的重型状态机（计划调度、步骤重试）应由上层框架实现
- Expert 模式的小型计划功能提供简化替代

## 替代方案

- 使用 **Expert 模式 + 小型计划功能**（3-15 步轻量计划）
- 使用 **Expert 模式 + 子 Agent 委派**
- 使用 **Expert 模式 + 并行作业**
- 或在上层框架基于 Expert 模式实现自定义编排
