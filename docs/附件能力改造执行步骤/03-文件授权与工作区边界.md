# 执行步骤 03：文件授权与工作区边界

> 状态：待执行 · 0%。前置：[02-附件工具与 Blob 生命周期](./02-附件工具与Blob生命周期.md)。

## 1. 目标

工作区内文件：延续 Runtime 默认读权限，不再弹窗。工作区外文件：复用现有 Host `NeedsPermission -> ToolPermissionRequest -> ToolPermissionResponse.Grant -> SaveGrant -> Gateway retry`，在宿主明确授权对应读/写根后执行。

不新增外部路径权限字段/数据库列，不另建附件上传审批。默认 scope 仍工作区内；读许可不能变写许可；写许可不能变读许可；覆盖、移动、删除分别保留现有独立高风险 flags。

## 2. 需要逐层修通

1. `BuiltinFsPathPolicy`: 分开安全路径规范化与权限范围检查。绝对外部目标可以被规范化但不自动授权；相对路径始终锚定 Workspace，拒绝借 `..` 走到外部。
2. `BuiltinToolConsentScopeResolver`: 外部 read/list/search 返回规范化的读 scope；create/overwrite/append/edit 返回写 scope 和独立覆盖意图。生成 scope 时不得读取/写入目标文件。
3. `ToolAuthorizationService`: `CoversRequestedScope` 对读/写根、风险 flags、ToolId/CallId 进行 scope 检查。安全但未获授权的外部文件必须变为现有 `NeedsPermission`；设备路径、ADS、reserved `.madorin`、危险链接/重解析点仍 fail closed，不申请后绕过。
4. `ToolGrantCalculator`: Normalize/Intersect/IsSubset 接纳经过 ScopeResolver 规范化的、与本次 filesystem 操作相符的显式外部根；默认 PermissionContext 仍只有 WorkspaceRoot。所有有效许可继续是 Host Grant、父 Grant、MaximumPermission 的最小交集。
5. `ToolConsentCoordinator`: host 返回 Grant 后按 scope 收窄，不允许宿主根超出本次用户看到并批准的操作。如果 host Grant 没有有限 ToolId 或读写维度，不能因外部路径请求顺带把 `mcli_process`/其他工具放入同一个更宽许可。
6. `ExpandRunFilesystemRoots`、Standalone Grant 与 Run 重用规则：小范围 file scope 不可扩为整个 workspace、盘符根或外部父目录。Once/Run 策略以已有 `CanGrantForRun` 行为为准并补测试。
7. Executor `ResolveReadPath`/`ResolveWritePath` 最终判定：Workspace 内走默认 root；外部只有显式相应根覆盖才执行。创建不存在的外部文件要安全验证已授权 parent root，不能因目标不存在就把 parent 自动授权。
8. Prepare 与 Execute 可能相隔用户审批/写锁等待；执行时重新规范化、重开并固定句柄，二次验证 root 和 `expectedHash`。授权不是对路径将来替换文件的无条件承诺。

## 3. 验收测试

- Workspace 内 read/attach 不要求人审；default write/new file 按既有 Restricted 行为不回归。
- 外部读未授权触发 exactly one Host Permission 请求；用户拒绝/宿主不可交互时不读取文件；批准之后同一次 tool call 以返回的 Grant 继续执行。
- 外部创建/写入只在 host 显式返回匹配 write root 后执行；无 overwrite flag 的已存在文件仍失败；move/delete 仍分别要求 flags/审批。
- 读 Grant 不可写，写 Grant 不可读，root 以路径 segment 精确比较，`C:\foo` 不覆盖 `C:\foobar`。
- 父 Grant、MaximumPermission、不同 Run/Agent、失效/撤销、CallId 绑定都不能被外部 root 绕过；Run Grant 不得扩大外部范围。
- Outside `../`、UNC/设备命名空间、ADS、`.madorin` 与 symlink/reparse 竞态继续拒绝。
- ToolGateway 与 Standalone 两种部署共享语义。记录审计摘要，不写文件内容。

## 4. 验收

既有 Host 授权通道被复用，外部读/写仅在对应显式 Grant scope 内执行；未授权仍默认拒绝，任何危险动作权限不被顺带扩大。
