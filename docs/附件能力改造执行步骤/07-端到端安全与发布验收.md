# 执行步骤 07：端到端、安全与发布验收

> 状态：待执行 · 0%。前置：步骤 01-06。

## 1. 业务闭环

从被授权本地文件开始逐阶段做真实 Integration：

```text
mcli_fs_attach
 -> 权限决策（workspace 默认 / workspace 外 host grant）
 -> 固定句柄和流式 Blob Store
 -> ToolResult 元数据 + BlobRef
 -> ToolResultContentBlock
 -> Provider Request Projection
 -> Worker 按权限流式读 Blob
 -> 厂商 native image/file/audio/video part 或 file upload id
 -> Provider response 文本与可选附件事件
 -> Runtime 持久化和 Outbox
 -> Host/Client event + Blob 下载及哈希校验
```

每段均检查真实数据 byte length/hash；不能只看有成功事件或日志写着附件 id。

## 2. 覆盖矩阵

- Files: PNG/JPEG/WebP/GIF、PDF、text/plain 文件附件、未知二进制分别验证。
- Audio: 真实波形编码、容器 MIME、文件上传/inline part 分开记录，不能误将音频理解能力与 TTS 输出能力混为一项。
- Video: 至少 MP4 容器真实样例。仅目标 API 文档明确支持且实际 endpoint 通过才标支持；不支持时原始错误可见，不自动抽帧。
- 大小: 小附件、接近单文件上限、大于 Worker 16 MiB 单帧但低于 Blob 配额、大于 Provider 上限分别验证。
- 所有十家 Provider 分 route/API/endpoint/model 记录输入与输出，能力字段 false/null 均不能在本地被当作硬门禁。

## 3. 安全和故障注入

- 权限：workspace 内默认、外部读/写 Grant、Grant root segment 边界、只读不写、撤销/过期、父 Grant、Agent、CallId/Run 绑定。
- 路径：UNC、设备 namespace、ADS、`.madorin`、symlink/reparse race、审批期间替换、超长路径。
- 内容：Hash/MIME/length spoof、已过期 blob、blob id 跨 Session 枚举、file_id 跨 Provider Key 复用、危险 URL SSRF。
- IPC：半 chunk、错序 chunk、重复 TransferId、stale InvocationId、frame oversize、取消/Worker kill/重启、慢读取/背压。
- 持久化：写 Blob 完成但 JSONL 未写、JSONL 写出但 Outbox 未更新、事件重复/replay、清理期间历史仍引用。
- 上下文：普通工具回执 JSON 中不含文件全文/Base64；Provider part 中有附件但 token accounting/ContextProjection 不把整份 base64 文本计入普通文本 prompt；附件 bytes 和引用 metadata 分离限额。

## 4. 性能/AOT

- 记录文件大小、chunk bytes、并发 transfer、峰值 managed/private memory、GC allocation、JSON frame 大小、HTTP request content length 与 token estimate。
- P0 图片附件与后续视频附件分别证明：文件全文未进入普通 prompt、工具结果文本或 Worker Invoke JSON；若 Provider 协议要求在网络 JSON 的原生附件字段使用 Base64/data URL，须证明它只存在于该字段、不参与普通文本/token 上下文，并显式记录 SDK 缓冲及峰值。P0 不要求视频附件支持，视频在其 Provider 路线纳入后再验。
- Windows Debug/Release 与 Provider/Runtime 测试零警告；Windows `win-x64` AOT CLI + 十 Worker 使用同一 IPC version 发布。
- Source-generated JSON context 覆盖全部 Worker 帧和协议内容；Native AOT trimming 不丢附件多态类型。发布包内 Worker manifest 与实际 exe 对齐。
- 当前发布基线以项目最新执行步骤为准；此清单的本地 build/test 不替代真实厂商 endpoint 验证。

## 6. 交付完成条件

- 01 的 P0 证明工具附件内容由原生附件通道传输，不是 JSON ref/base64 prompt。
- 工作区默认授权、工作区外 Host Grant 读写 scope 和危险操作边界通过集成测试。
- Worker 双向传输取消、背压、配额、SHA 和多调用隔离闭合。
- 十 Provider 输入和输出分别报告真实/模拟状态，所有不支持情况清楚表达。
