# 事件模型

> Runtime 事件流与消息格式详细规范

本文档描述 Runtime 的事件模型，包括事件类型、事件流、序列号机制和可靠投递。

## 概述

Runtime 通过事件流向宿主应用传递执行过程中的所有信息。事件流是异步的、有序的、可重放的。

### 核心特性

- **异步流式**：事件实时推送，不需要轮询
- **有序投递**：通过全局序列号（GSN）和 Run 序列号保证顺序
- **可重放**：支持从任意 GSN 开始重放事件
- **确认机制**：客户端定期确认，支持断线重连
- **类型安全**：所有事件都有明确的类型定义

## 事件封装

所有事件都包装在 `RuntimeEventEnvelope` 中：

```csharp
public sealed record RuntimeEventEnvelope(
    string RuntimeInstanceId,    // Runtime 实例 ID
    long Gsn,                     // 全局序列号（Global Sequence Number）
    string RunId,                 // 关联的 Run ID
    long RunSequence,             // Run 内序列号
    string MessageType,           // 事件类型
    DateTimeOffset Timestamp,     // 时间戳
    JsonElement Payload           // 事件负载
);
```

### 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `RuntimeInstanceId` | string | Runtime 实例唯一标识 |
| `Gsn` | long | 全局序列号，单调递增，跨所有 Run |
| `RunId` | string | 关联的 Run ID（UUID） |
| `RunSequence` | long | Run 内序列号，从 1 开始 |
| `MessageType` | string | 事件类型，如 "output.delta" |
| `Timestamp` | DateTimeOffset | 事件生成时间戳 |
| `Payload` | JsonElement | 事件具体数据 |

### 示例

```json
{
  "runtimeInstanceId": "runtime-abc123",
  "gsn": 42,
  "runId": "run-def456",
  "runSequence": 5,
  "messageType": "output.delta",
  "timestamp": "2026-09-18T12:34:56.789Z",
  "payload": {
    "invocationId": "inv-789",
    "delta": "你好"
  }
}
```

## 事件类型

### Run 生命周期事件

#### run.accepted

Run 已被接受并开始执行。

```json
{
  "messageType": "run.accepted",
  "payload": {
    "runId": "run-123",
    "sessionId": "session-456",
    "mode": "Expert"
  }
}
```

#### run.status.changed

Run 状态变化。

```json
{
  "messageType": "run.status.changed",
  "payload": {
    "runId": "run-123",
    "status": "Running",
    "previousStatus": "Pending"
  }
}
```

**状态枚举**：

- `Pending`：待执行
- `Running`：执行中
- `Completed`：已完成
- `Failed`：失败
- `Cancelled`：已取消

#### run.completed

Run 成功完成。

```json
{
  "messageType": "run.completed",
  "payload": {
    "runId": "run-123",
    "sessionId": "session-456"
  }
}
```

#### run.failed

Run 执行失败。

```json
{
  "messageType": "run.failed",
  "payload": {
    "runId": "run-123",
    "code": "ProviderUnavailable",
    "message": "Failed to connect to AI service",
    "details": {
      "httpStatusCode": 503
    }
  }
}
```

**常见错误码**：

| 错误码 | 说明 |
| --- | --- |
| `ProviderUnavailable` | Provider 服务不可用 |
| `AuthenticationFailed` | 认证失败 |
| `RateLimitExceeded` | 超过速率限制 |
| `TimeoutExceeded` | 超时 |
| `InternalError` | Runtime 内部错误 |

#### run.cancelled

Run 被取消。

```json
{
  "messageType": "run.cancelled",
  "payload": {
    "runId": "run-123",
    "reason": "User cancelled"
  }
}
```

### 输出事件

#### output.delta

文本增量输出（流式）。

```json
{
  "messageType": "output.delta",
  "payload": {
    "invocationId": "inv-123",
    "delta": "这是"
  }
}
```

随后的事件：

```json
{
  "messageType": "output.delta",
  "payload": {
    "invocationId": "inv-123",
    "delta": "一段"
  }
}
```

```json
{
  "messageType": "output.delta",
  "payload": {
    "invocationId": "inv-123",
    "delta": "文本"
  }
}
```

宿主应累积所有 `delta` 得到完整输出："这是一段文本"。

#### reasoning.delta

推理过程增量输出（如 Claude 的思考过程）。

```json
{
  "messageType": "reasoning.delta",
  "payload": {
    "invocationId": "inv-123",
    "delta": "首先分析问题..."
  }
}
```

### 工具调用事件

#### tool.call.request

工具调用请求（AI 请求调用工具）。

```json
{
  "messageType": "tool.call.request",
  "payload": {
    "invocationId": "inv-123",
    "toolCallId": "call-789",
    "toolId": "host.search",
    "displayName": "search_database"
  }
}
```

#### tool.call.delta

工具调用参数增量。

```json
{
  "messageType": "tool.call.delta",
  "payload": {
    "invocationId": "inv-123",
    "toolCallId": "call-789",
    "argumentDelta": "{\"query\": \""
  }
}
```

```json
{
  "messageType": "tool.call.delta",
  "payload": {
    "invocationId": "inv-123",
    "toolCallId": "call-789",
    "argumentDelta": "用户数据"
  }
}
```

```json
{
  "messageType": "tool.call.delta",
  "payload": {
    "invocationId": "inv-123",
    "toolCallId": "call-789",
    "argumentDelta": "\"}"
  }
}
```

累积后得到完整参数：`{"query": "用户数据"}`

#### tool.call.completed

工具调用完成。

```json
{
  "messageType": "tool.call.completed",
  "payload": {
    "invocationId": "inv-123",
    "toolCallId": "call-789",
    "result": {
      "success": true,
      "data": [{"id": 1, "name": "用户A"}]
    }
  }
}
```

### Provider 调用事件

#### invocation.started

Provider 调用开始。

```json
{
  "messageType": "invocation.started",
  "payload": {
    "invocationId": "inv-123",
    "providerId": "my-openai",
    "model": "gpt-4o"
  }
}
```

#### invocation.completed

Provider 调用完成。

```json
{
  "messageType": "invocation.completed",
  "payload": {
    "invocationId": "inv-123"
  }
}
```

#### invocation.failed

Provider 调用失败。

```json
{
  "messageType": "invocation.failed",
  "payload": {
    "invocationId": "inv-123",
    "code": "RateLimitExceeded",
    "message": "Rate limit exceeded, retry after 60s"
  }
}
```

### 用量事件

#### usage.updated

Token 用量更新。

```json
{
  "messageType": "usage.updated",
  "payload": {
    "invocationId": "inv-123",
    "inputTokens": 150,
    "outputTokens": 80,
    "totalTokens": 230,
    "cacheReadTokens": 0,
    "cacheCreationTokens": 0
  }
}
```

### 能力投影事件

#### provider.projection.adjusted

Provider 能力投影变化（如切换模型后某些能力不再可用）。

```json
{
  "messageType": "provider.projection.adjusted",
  "payload": {
    "providerId": "my-openai",
    "capabilities": ["Streaming", "ToolCalling", "Vision"],
    "removedCapabilities": ["ComputerUse"],
    "reason": "Model switch to gpt-4o"
  }
}
```

### 凭据事件

#### credentials.refresh.requested

Provider 认证失败，需要更新凭据。

```json
{
  "messageType": "credentials.refresh.requested",
  "payload": {
    "providerId": "my-openai",
    "reason": "HTTP 401: Invalid API Key"
  }
}
```

宿主收到此事件后应调用 `UpdateCredentialsAsync` 提供新凭据。

### 上下文投影事件

#### context.projection.adjusted

上下文投影调整（如历史消息被截断以适应上下文窗口）。

```json
{
  "messageType": "context.projection.adjusted",
  "payload": {
    "sessionId": "session-456",
    "originalMessageCount": 50,
    "projectedMessageCount": 30,
    "reason": "Context window limit reached",
    "droppedMessageIds": ["msg-1", "msg-2", "..."]
  }
}
```

### 增量丢弃事件

#### delta.dropped

部分增量被丢弃（通常是因为速率限制或网络问题）。

```json
{
  "messageType": "delta.dropped",
  "payload": {
    "invocationId": "inv-123",
    "reason": "Buffer overflow",
    "estimatedCharactersDropped": 50
  }
}
```

## 事件流处理

### 客户端读取事件

```csharp
await foreach (var evt in client.ReadEventsAsync(eventReplayCursor: 0))
{
    switch (evt.MessageType)
    {
        case "output.delta":
            var delta = evt.Payload.Deserialize<TextDeltaEvent>();
            Console.Write(delta.Delta);
            break;
        
        case "tool.call.request":
            var toolCall = evt.Payload.Deserialize<ToolCallRequestEvent>();
            HandleToolCallRequest(toolCall);
            break;
        
        case "run.completed":
            var completed = evt.Payload.Deserialize<RunCompletedEvent>();
            Console.WriteLine("\nRun completed!");
            return;
        
        case "run.failed":
            var failed = evt.Payload.Deserialize<RunFailedEvent>();
            Console.WriteLine($"\nRun failed: {failed.Message}");
            return;
    }
}
```

### 事件确认

客户端应定期确认已处理的事件：

```csharp
long lastGsn = 0;
int eventCount = 0;

await foreach (var evt in client.ReadEventsAsync(0))
{
    ProcessEvent(evt);
    
    lastGsn = evt.Gsn;
    eventCount++;
    
    // 每处理 10 个事件确认一次
    if (eventCount % 10 == 0)
    {
        await client.AcknowledgeEventsAsync(lastGsn);
    }
}

// 最后确认
if (lastGsn > 0)
{
    await client.AcknowledgeEventsAsync(lastGsn);
}
```

### 断线重连

```csharp
// 保存上次确认的 GSN
long lastConfirmedGsn = LoadLastConfirmedGsn();

// 重连后从上次位置继续
await foreach (var evt in client.ReadEventsAsync(lastConfirmedGsn + 1))
{
    // 处理事件
    ProcessEvent(evt);
    
    // 定期确认
    if (evt.Gsn % 10 == 0)
    {
        await client.AcknowledgeEventsAsync(evt.Gsn);
        SaveLastConfirmedGsn(evt.Gsn);
    }
}
```

## 序列号机制

### 全局序列号（GSN）

- 单个 Runtime 实例内全局唯一
- 单调递增，从 1 开始
- 跨所有 Session 和 Run
- 用于事件重放和确认

### Run 序列号

- 单个 Run 内唯一
- 单调递增，从 1 开始
- 用于 Run 内事件排序

### 示例

```
GSN  Run ID      RunSeq  Event
1    run-A       1       run.accepted
2    run-A       2       output.delta ("你")
3    run-A       3       output.delta ("好")
4    run-A       4       run.completed
5    run-B       1       run.accepted
6    run-B       2       output.delta ("世")
7    run-B       3       output.delta ("界")
8    run-B       4       run.completed
```

## 事件过滤

### 按 Run 过滤

```csharp
await foreach (var evt in client.ReadEventsAsync(0))
{
    if (evt.RunId == targetRunId)
    {
        ProcessEvent(evt);
    }
}
```

### 按事件类型过滤

```csharp
await foreach (var evt in client.ReadEventsAsync(0))
{
    if (evt.MessageType.StartsWith("output."))
    {
        // 只处理输出相关事件
        ProcessOutputEvent(evt);
    }
}
```

### 按时间过滤

```csharp
var since = DateTimeOffset.UtcNow.AddHours(-1);

await foreach (var evt in client.ReadEventsAsync(0))
{
    if (evt.Timestamp >= since)
    {
        ProcessEvent(evt);
    }
}
```

## 事件重放

### 完整重放

从 GSN 0 开始重放所有事件：

```csharp
await foreach (var evt in client.ReadEventsAsync(0))
{
    ReplayEvent(evt);
}
```

### 增量重放

从上次位置继续：

```csharp
long lastGsn = GetLastProcessedGsn();

await foreach (var evt in client.ReadEventsAsync(lastGsn + 1))
{
    ProcessEvent(evt);
}
```

### 窗口重放

重放最近 N 个事件：

```csharp
long currentGsn = await GetCurrentGsnAsync();
long startGsn = Math.Max(0, currentGsn - 100);

await foreach (var evt in client.ReadEventsAsync(startGsn))
{
    if (evt.Gsn > currentGsn)
        break;
    
    ReplayEvent(evt);
}
```

## 事件存储

Runtime 将所有事件存储在 SQLite 数据库中：

```sql
CREATE TABLE Events (
    Gsn INTEGER PRIMARY KEY,
    RuntimeInstanceId TEXT NOT NULL,
    RunId TEXT NOT NULL,
    RunSequence INTEGER NOT NULL,
    MessageType TEXT NOT NULL,
    Timestamp TEXT NOT NULL,
    Payload TEXT NOT NULL
);

CREATE INDEX idx_events_runid ON Events(RunId);
CREATE INDEX idx_events_timestamp ON Events(Timestamp);
```

## 性能考虑

### 批量处理

批量处理事件以减少 I/O：

```csharp
var batch = new List<RuntimeEventEnvelope>();
const int batchSize = 10;

await foreach (var evt in client.ReadEventsAsync(0))
{
    batch.Add(evt);
    
    if (batch.Count >= batchSize)
    {
        ProcessBatch(batch);
        batch.Clear();
    }
}

if (batch.Any())
{
    ProcessBatch(batch);
}
```

### 异步处理

使用后台任务处理事件：

```csharp
var channel = Channel.CreateUnbounded<RuntimeEventEnvelope>();

// 读取线程
_ = Task.Run(async () =>
{
    await foreach (var evt in client.ReadEventsAsync(0))
    {
        await channel.Writer.WriteAsync(evt);
    }
    channel.Writer.Complete();
});

// 处理线程
await foreach (var evt in channel.Reader.ReadAllAsync())
{
    ProcessEvent(evt);
}
```

### 限流

避免事件处理过快导致 UI 卡顿：

```csharp
var rateLimiter = new RateLimiter(maxEventsPerSecond: 100);

await foreach (var evt in client.ReadEventsAsync(0))
{
    await rateLimiter.WaitAsync();
    ProcessEvent(evt);
}
```

## 完整示例

### 控制台输出处理

```csharp
public class ConsoleEventProcessor
{
    private readonly IRuntimeClient _client;
    private long _lastConfirmedGsn;
    
    public async Task ProcessEventsAsync(string runId)
    {
        var outputBuffer = new StringBuilder();
        
        await foreach (var evt in _client.ReadEventsAsync(_lastConfirmedGsn + 1))
        {
            if (evt.RunId != runId)
                continue;
            
            switch (evt.MessageType)
            {
                case "output.delta":
                    var delta = evt.Payload.Deserialize<TextDeltaEvent>();
                    outputBuffer.Append(delta.Delta);
                    Console.Write(delta.Delta);
                    break;
                
                case "tool.call.request":
                    var toolCall = evt.Payload.Deserialize<ToolCallRequestEvent>();
                    Console.WriteLine($"\n[Tool: {toolCall.DisplayName}]");
                    break;
                
                case "usage.updated":
                    var usage = evt.Payload.Deserialize<UsageUpdatedEvent>();
                    Console.WriteLine($"\n[Usage: {usage.TotalTokens} tokens]");
                    break;
                
                case "run.completed":
                    Console.WriteLine("\n✓ Completed");
                    await AcknowledgeAsync(evt.Gsn);
                    return;
                
                case "run.failed":
                    var failed = evt.Payload.Deserialize<RunFailedEvent>();
                    Console.WriteLine($"\n✗ Failed: {failed.Message}");
                    await AcknowledgeAsync(evt.Gsn);
                    return;
            }
            
            // 每 10 个事件确认一次
            if (evt.Gsn % 10 == 0)
            {
                await AcknowledgeAsync(evt.Gsn);
            }
        }
    }
    
    private async Task AcknowledgeAsync(long gsn)
    {
        await _client.AcknowledgeEventsAsync(gsn);
        _lastConfirmedGsn = gsn;
    }
}
```
