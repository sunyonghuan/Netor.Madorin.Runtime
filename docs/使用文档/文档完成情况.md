## 核心亮点

### 使用方式

1. **独立 CLI**：`madorin run`、`madorin serve`
2. **SDK 集成**：`Madorin.AI.Runtime.Client` NuGet 包

### Provider 开发

1. **语言无关**：任何能读写 stdin/stdout 和解析 JSON 的语言
2. **C# 优先**：提供 `ProviderWorkerHost` 基础设施，开箱即用
3. **进程复用**：每个协议 slug 一个 Worker，支持多连接

### 协议设计

1. **认证安全**：基于时间戳和哈希的握手
2. **事件可靠性**：GSN 序列号 + 确认机制 + 重放
3. **幂等性**：Session/Run 创建通过 IdempotencyKey 保证
4. **取消支持**：Run 取消和 Provider 调用取消
