# 快速开始

> 5 分钟快速上手 Madorin.AI.Runtime

本指南帮助你快速体验 Runtime 的核心功能，包括安装、配置和第一次 AI 对话。

## 环境要求

- **.NET 10 SDK**（构建时需要，运行已发布的二进制文件不需要）
- **Windows 10+** / **Linux** / **macOS**（当前主要在 Windows 上验证）
- **AI 服务 API Key**（OpenAI、Anthropic、DeepSeek 等任意一个）

## 安装

### 从发布包安装

下载对应平台的发布包并解压：

```bash
# Windows
releases/Madorin-Cli/madorin-cli/bin/madorin-cli.exe

# Linux / macOS
releases/Madorin-Cli/madorin-cli/bin/madorin-cli
```

将 `bin` 目录添加到 `PATH` 环境变量（可选但推荐）。

### 从源码构建

```bash
# 克隆仓库
git clone <repository-url>
cd Netor.Madorin.Ai.Runtime

# 构建
dotnet build Madorin.AI.Runtime.slnx -c Release

# 运行（无需安装）
dotnet run --project src/Madorin.AI.Runtime.Cli --no-build -- --help
```

## 初始化配置

首次运行需要初始化配置文件：

```bash
madorin config init
```

配置向导会引导你完成：

1. **选择 Provider**：OpenAI、Anthropic、DeepSeek、Kimi、Custom 等
2. **输入 API Key**：你的模型服务 API 密钥
3. **选择默认模型**：支持在线发现或手动输入
4. **（可选）配置运行环境**：按 Provider 要求填写地址、认证方式和模型列表

配置文件保存在 `~/.madorin/config.json`。

### 配置示例

```json
{
  "defaultProvider": "my-openai",
  "defaultModel": "gpt-5",
  "defaultAgent": "default",
  "providers": [
    {
      "name": "my-openai",
      "protocol": "OpenAI",
      "apiKey": "sk-...",
      "baseUrl": "https://api.openai.com/v1",
      "models": ["gpt-5"]
    }
  ]
}
```

这是全局独立 CLI 配置的示意；工作区配置只覆盖默认 Provider、模型和 Agent，详细结构见[独立 CLI 使用指南](./02-独立CLI使用指南.md#配置文件结构)。

## 第一次对话

### 方式一：交互式 REPL

启动单行 REPL（不带任何命令）：

```bash
madorin
```

然后输入你的问题：

```
> 你好，请介绍一下自己
```

按 `Ctrl+D`（Linux/macOS）或 `Ctrl+Z` + `Enter`（Windows）结束输入并发送。

### 方式二：单次命令

```bash
madorin run --input "用三句话介绍量子计算"
```

### 方式三：从文件输入

```bash
echo "分析一下这段代码的性能问题" > task.txt
madorin run --input-file task.txt --output-file result.txt
```

## 会话管理

Runtime 会自动创建和管理会话（Session）：

```bash
# 列出最近 20 条活动会话（默认状态 active）
madorin session list

# 包括归档会话
madorin session list --status all

# 查看会话详情
madorin session show <session-id>

# 继续之前的会话
madorin run --session <session-id> --input "继续刚才的话题"

# 导出会话
madorin session export <session-id> --format jsonl --output conversation.jsonl
```

在交互式 REPL 内可输入 `/resume` 查看最近 10 条 Session，使用 `/resume 20` 指定列表条数（1–100），再用 `/resume <session-id>` 继续。列表显示本地时间，精确到秒。帮助语言可用 `/help en` 和 `/help zh` 切换。

`madorin session list` 默认只列出最近 20 条活动会话；归档会话使用 `--status archived`，状态默认包含范围可用 `--status all` 查询。

## Expert 模式

Runtime 采用 Expert 模式进行深度分析和复杂决策：

```bash
# 基础对话
madorin run --input "分析这个系统的架构问题"

# 带自定义参数控制（温度、最大Token等）
madorin run --input "生成创意方案" --temperature 1.5 --max-tokens 4000
```

Expert 模式支持子 Agent 委派、工具调用和精细化请求参数控制。

详见 [独立 CLI 使用指南](./02-独立CLI使用指南.md)。

## 常驻服务模式

对于需要长期运行或集成到应用程序的场景，可以启动常驻服务：

```bash
# 生成握手密钥；生产环境应从密钥管理服务注入
export MADORIN_HANDSHAKE_SECRET="$(openssl rand -base64 32)"

# 启动 Runtime Server：workspace 必填，密钥通过 stdin 第一行传入
printf '%s\n' "$MADORIN_HANDSHAKE_SECRET" | madorin serve --workspace /path/to/project --instance main
```

服务在前台运行。打开另一个终端查询实例状态；客户端连接时提供同一握手密钥。

```bash
madorin ctl status --instance main
```

详见 [SDK 集成指南](./03-SDK集成指南.md)。

## 工作区隔离

每个目录可以有独立的数据和配置：

```bash
# 在项目目录下运行
cd /path/to/my-project
madorin run --input "分析这个项目的代码结构"

# Runtime 会在 .madorin/ 目录下保存数据
ls .madorin/
# state.db  messages/  blobs/  checkpoints/  logs/
```

可以在项目根目录创建 `.madorin/config.json` 覆盖全局配置。

## 数据位置

| 位置 | 内容 |
| --- | --- |
| `~/.madorin/config.json` | 全局配置（Provider、默认模型） |
| `~/.madorin/agents/` | 自定义 Agent 定义 |
| `<workspace>/.madorin/` | 工作区数据（会话、消息、Blob） |
| `<workspace>/.madorin/config.json` | 工作区配置（可选，覆盖全局） |

## 常见命令速查

| 命令 | 说明 |
| --- | --- |
| `madorin` | 启动交互式 REPL |
| `madorin run` | 执行单次任务 |
| `madorin serve` | 启动常驻服务 |
| `madorin doctor` | 检查环境状态 |
| `madorin config init` | 初始化配置 |
| `madorin config edit` | 编辑配置文件 |
| `madorin session list` | 列出最近 20 条活动会话 |
| `madorin db check` | 检查数据库 |
| `madorin --help` | 查看完整命令帮助 |

## 输出格式

支持三种输出格式：

```bash
# 文本格式（默认，人类可读）
madorin run --input "你好" --output-format text

# JSON 格式（单个 JSON 对象）
madorin run --input "你好" --output-format json

# JSONL 格式（流式事件，每行一个 JSON）
madorin run --input "你好" --output-format jsonl
```

## 故障排查

### 配置问题

```bash
# 验证配置文件
madorin config validate

# 检查 Provider 连接
madorin doctor
```

### 网络问题

```bash
# 设置代理
madorin config init  # 在向导中配置代理

# 或直接编辑配置文件
madorin config edit
```

### 数据库问题

```bash
# 检查数据库完整性
madorin db check

# 修复数据库
madorin db repair
```
