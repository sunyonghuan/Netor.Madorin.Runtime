# Madorin 控制台测试宿主 · 命令层次与菜单树

> 文档状态：策划草案，未实现
>
> 编写日期：2026-07-27
>
> 上级文档：[00-总体策划](./00-总体策划.md)
>
> **定位：次要层。** 本文覆盖 `madorin` **独立命令**，属于控制台测试台的**次要层**——这些命令本就能单独执行验证。控制台的**重点**是作为宿主测 serve 模式，见[05-serve 宿主深度测试设计](./05-serve宿主深度测试设计.md)。其中 `serve` 命令本身在这里只登记为“如何拉起被测实例”，其宿主交互全部在 05 文档。

本文把全部**已注册**的独立命令组织成分层菜单树，并标注每条命令的风险等级、读写性质和锁要求，供测试者判断执行顺序和影响面。命令面以源码 `CliApplication.CreateRootCommandCore` 为准。

## 图例

- 风险等级：🟢 只读/低风险 · 🟡 写数据/需注意 · 🔴 危险/需确认（删除、修复、清理、迁移）
- 锁：`无` / `配置写锁` / `记忆写锁` / `工作区写锁` / `Runtime 绑定`
- 默认建议：危险命令优先走 `--dry-run` 或先确认

## 1. 服务与执行

| 菜单项 | 命令 | 风险 | 读写 | 锁 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1.1 单次任务 | `run` | 🟡 | 写 Session/Run/消息/事件/工具审计 | 工作区写锁 | 非交互执行一次对话；测试台默认 `--no-stream` 便于采集 |
| 1.2 进入 REPL | `run`（无 `--input`） | 🟡 | 同上 | 工作区写锁 | 交互模式；斜杠命令见本文末节 |
| 1.3 启动常驻服务 | `serve` | 🟡 | 持续写 Runtime 状态 | 工作区写锁，全生命周期持有 | 后台启动供 `ctl` 与实时监控使用；必须显式 `--workspace` |

| 4.3 追加记忆 | `memory add <scope>` | 🟡 | 追加（从 stdin 读一行） | 记忆写锁 | 测试台从向导输入喂给 stdin |

## 8. 在线控制（ctl）

> 连接**正在运行**的 Runtime 实例。握手 secret 只从 `MADORIN_AI_RUNTIME_SECRET` 读取，不作为参数、不写入任何输出。未显式 `--instance` 时只允许解析当前工作区唯一实例。

| 菜单项 | 命令 | 风险 | 读写 | 锁 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 8.1 实例状态 | `ctl status` | 🟢 | 只读 Runtime 状态 | Runtime 绑定 | `--instance` |
| 8.2 会话列表 | `ctl sessions` | 🟢 | 只读 Session 列表 | Runtime 绑定 | `--instance` |
| 8.3 Run 列表 | `ctl runs` | 🟢 | 只读 Run 列表 | Runtime 绑定 | `--instance --session` |
| 8.4 取消 Run | `ctl cancel <runId>` | 🟡 | 请求取消 Run | Runtime 绑定 | `--instance --reason`；成功仅表示 accepted |
| 8.5 更新凭据 | `ctl credential update` | 🟡 | 从环境变量推送新凭据 | Runtime 绑定 | `--run --provider --api-key-env` 必填；`--instance --profile --expires-at` 可选 |

失败码：认证失败 `3`；实例发现/PID/Pipe/连接问题 `5`；参数错误 `2`；Runtime 拒绝 `1`。

## 9. 交互模式（REPL）斜杠命令速查

在 `run` 无 `--input` 进入的交互模式下可用。以源码 `ReplHelpWriter` 为准（含规范文档未列出的 `/memory`、`/remember`、`/skill`）：

```text
/model [id]        查看或切换下一轮模型
/provider [id]     查看或切换下一轮 Provider
/agent [id]        查看或切换下一轮 Agent
/mode              显示当前运行模式（会话内不允许切换）
/compact           立即压缩当前会话上下文
/context           显示当前上下文投影状态
/session           显示当前会话信息
/new               开始新会话（当前会话保存并关闭）
/resume [id]       切换到指定会话；无参列出最近会话
/export [path]     导出当前会话为 Markdown；无参输出到 stdout
/tools             显示当前 Run 可用工具与权限
/history [n]       显示最近 n 条消息（默认 5，all 全部）
/memory            记忆相关操作
/remember          记录一条记忆
/skill             Skills 相关操作
/status            显示 Runtime 当前状态
/clear             清屏（不清历史）
/help [command]    显示命令帮助
/exit  /quit       保存会话并退出
```

> 测试台在 REPL 场景下提供一个“斜杠命令速查/发送”辅助面板，把上表作为快捷输入，减少手敲。
