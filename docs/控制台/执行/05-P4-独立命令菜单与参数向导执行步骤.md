完成标准：

- 向导可以生成稳定 argv。
- Secret 不进入 argv 明文。
- stdin 输入和参数输入区分清楚。

## 6. P4-05 本地预校验

当前进度：100%

必须拦截的组合：

| 规则 | 期望 |
| --- | --- |
| `run --input` 与 `--input-file` 同时出现 | 拦截，提示真实命令会返回 2 |
| `run --output-file` 未配合输入 | 拦截 |
| `run` 交互模式下使用 JSON/JSONL/`--no-stream` | 拦截 |
| `run --json` 与非 JSON `--output-format` 同时出现 | 拦截 |
| `serve` 缺少 `--workspace` | 拦截 |
| `doctor --yes` 未配合 `--fix` | 拦截 |
| `storage gc --dry-run` 与 `--confirm` 同时出现 | 拦截 |
| `session delete` 缺少 `--confirm` | 拦截 |
| `ctl credential update` 缺少必填项 | 拦截 |

执行步骤：

1. 把预校验规则定义在 Catalog 或独立 validator 中。

4. 预校验只是提速，最终仍以真实命令退出码为准。
5. 提供“仍要执行”开关时必须默认关闭；建议本轮不开放。

完成标准：

- 固定错误组合在本地拦截。
- 错误提示能指出具体冲突参数。
- 预校验不替代服务端校验。
