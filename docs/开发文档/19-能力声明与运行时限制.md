# 能力声明与运行时限制

> 当前生效版本：Madorin.AI.Runtime V1
>
> 本文描述 Runtime 和 Provider 的能力声明格式以及内置硬编码限制。能力声明在初始化阶段完成，影响可用功能集。

## 1. 概述

Runtime 和 Provider 通过两个独立的 record 类型声明各自支持的能力。`RuntimeCapabilities` 由宿主在 `serve` 握手时传入，描述宿主侧和 Runtime 整体支持的功能；`ProviderCapabilities` 由每个 Provider 适配器声明，描述具体模型协议支持的功能。两者共同决定一轮 Invocation 中可用的特性集。

此外，`RuntimeLimits` 定义协议帧和内容的体积上限，各内置工具定义自身的硬编码限制。

## 2. RuntimeCapabilities

```csharp
public sealed record RuntimeCapabilities(
    bool Streaming = true,
    bool ToolCalling = true,
    bool BlobTransfer = true,
    bool MultiRun = true,
    bool SessionResume = true,
    bool? ReverseRpc = null,
    bool? ToolCatalog = null,
    bool? ToolPermissions = null,
    SkillsCapabilities? Skills = null);
```

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Streaming` | `bool` | `true` | 是否支持流式输出（`output.delta` 事件） |
| `ToolCalling` | `bool` | `true` | 是否支持工具调用 |
| `BlobTransfer` | `bool` | `true` | 是否支持通过 Blob 通道传输大体积工具结果 |
| `MultiRun` | `bool` | `true` | 是否支持同一 Session 内多次 Run |
| `SessionResume` | `bool` | `true` | 是否支持 Session 恢复 |
| `ReverseRpc` | `bool?` | `null` | 是否启用反向 RPC（`host.*`、`mcp.*` 工具）。`null` 表示由运行环境决定 |
| `ToolCatalog` | `bool?` | `null` | 是否支持动态工具目录（`tool.catalog.replace` / `tool.catalog.patch`）。`null` 表示由运行环境决定 |
| `ToolPermissions` | `bool?` | `null` | 是否支持工具权限回调。`null` 表示由运行环境决定 |
| `Skills` | `SkillsCapabilities?` | `null` | 技能系统能力，`null` 表示不声明（使用默认配置） |

核心能力（`Streaming`、`ToolCalling`、`BlobTransfer`、`MultiRun`、`SessionResume`）默认为 `true`，表示标准 Runtime 默认全部开启。可空布尔值（`ReverseRpc`、`ToolCatalog`、`ToolPermissions`）的语义为"未声明，由上下文决定"——独立 CLI 模式下通常默认关闭，宿主集成模式下由宿主显式传入。

序列化时，可空字段使用 `JsonIgnoreCondition.WhenWritingNull`，不会出现在 JSON 输出中。

## 3. SkillsCapabilities

嵌套在 `RuntimeCapabilities.Skills` 中的 record，描述技能系统支持范围：

```csharp
public sealed record SkillsCapabilities(
    bool Enabled = true,
    string[]? SourceKinds = null,
    bool ResourcesSupported = true,
    bool ScriptsSupported = true,
    bool HotRefreshSupported = true);
```

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Enabled` | `bool` | `true` | 是否启用 Skills 系统 |
| `SourceKinds` | `string[]?` | `null` | 允许的技能来源类型，如 `["Directory"]`。`null` 表示接受所有类型 |
| `ResourcesSupported` | `bool` | `true` | 是否支持资源文件（`.md`、`.json` 等）注入上下文 |
| `ScriptsSupported` | `bool` | `true` | 是否支持脚本文件（`.ps1`、`.sh`、`.py` 等）作为工具暴露 |
| `HotRefreshSupported` | `bool` | `true` | 是否支持文件系统监控和热刷新 |

## 4. ProviderCapabilities

由每个 Provider 适配器在构造时声明，描述该 Provider 协议支持的功能子集：

```csharp
public sealed record ProviderCapabilities(
    bool Streaming = false,
    bool ToolCalling = true,
    bool Vision = false,
    bool Audio = false,
    bool StructuredOutput = false,
    bool Reasoning = false,
    bool PromptCaching = false,
    bool Files = false,
    bool ComputerUse = false,
    bool Embeddings = false,
    bool Usage = false,
    bool RemoteCancellation = false);
```

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `Streaming` | `false` | 支持服务端流式推送 |
| `ToolCalling` | `true` | 支持工具/函数调用 |
| `Vision` | `false` | 支持视觉（图片）输入 |
| `Audio` | `false` | 支持音频输入/输出 |
| `StructuredOutput` | `false` | 支持结构化输出（JSON Schema 约束） |
| `Reasoning` | `false` | 支持推理/思考链输出 |
| `PromptCaching` | `false` | 支持 Prompt Caching（前缀复用） |
| `Files` | `false` | 支持文件上传 |
| `ComputerUse` | `false` | 支持 Computer Use（屏幕操作） |
| `Embeddings` | `false` | 支持向量嵌入 |
| `Usage` | `false` | 响应中包含 Token 用量信息 |
| `RemoteCancellation` | `false` | 支持远程取消（服务端中断推理） |

与 `RuntimeCapabilities` 不同，`ProviderCapabilities` 的核心能力默认值更保守：只有 `ToolCalling` 默认开启，其余默认关闭。每个 Provider 需显式声明自身支持的功能。

## 5. RuntimeLimits

定义协议帧和内容的体积上限：

```csharp
public sealed record RuntimeLimits(
    int MaxControlMessageBytes = 1048576,
    int MaxEventFrameBytes = 4194304,
    int MaxInlineContentBytes = 65536,
    long MaxBlobBytes = 1073741824L,
    long MaxBlobBytesPerRun = 4294967296L,
    int? MaxToolRounds = null,
    int? MaxToolCallsPerRound = null,
    long? MaxToolResultBytesPerInvocation = null);
```

| 限制 | 默认值 | 说明 |
| --- | --- | --- |
| `MaxControlMessageBytes` | 1 MB (1,048,576) | 控制通道单条消息最大字节数 |
| `MaxEventFrameBytes` | 4 MB (4,194,304) | 事件帧最大字节数 |
| `MaxInlineContentBytes` | 64 KB (65,536) | 工具结果内联返回最大字节数，超出部分通过 Blob 通道传输 |
| `MaxBlobBytes` | 1 GB (1,073,741,824) | 单个 Blob 最大字节数 |
| `MaxBlobBytesPerRun` | 4 GB (4,294,967,296) | 单次 Run 的 Blob 总量上限 |
| `MaxToolRounds` | `null` | 工具循环最大轮数。`null` 表示不限制（由 Provider 或模型决定） |
| `MaxToolCallsPerRound` | `null` | 每轮最大工具调用次数。`null` 表示不限制 |
| `MaxToolResultBytesPerInvocation` | `null` | 单次工具调用结果最大字节数。`null` 表示不限制 |

可空限制字段使用 `JsonIgnoreCondition.WhenWritingNull`。宿主可在初始化时传入自定义 `RuntimeLimits` 覆盖默认值。

## 6. 内置工具限制

以下为各内置工具在源码中硬编码的限制常量，不受 `RuntimeLimits` 配置影响。

### 6.1 HTTP 工具 (`http.request`)

| 限制 | 值 | 说明 |
| --- | --- | --- |
| 默认响应体上限 | 1 MB (1,048,576) | `DefaultMaxResponseBytes`，可通过 `NetworkPolicy.MaxResponseBytes` 调整 |
| 硬上限响应体 | 4 MB (4,194,304) | `HardMaxResponseBytes`，不可超越 |
| 请求体上限 | 1 MB (1,048,576) | `MaxRequestBodyBytes` |
| 请求头数量上限 | 64 | `MaxRequestHeaders` |
| 响应头数量上限 | 128 | `MaxResponseHeaders` |
| 重定向次数上限 | 10 | 通过 `NetworkPolicy.MaxRedirects` 配置，范围 0–10，默认 0 |

### 6.2 进程工具 (`process.execute`)

| 限制 | 值 | 说明 |
| --- | --- | --- |
| 参数数量上限 | 128 | `MaxArgumentCount` |
| 单参数长度上限 | 8,192 字符 | `MaxArgumentLength` |
| 环境变量数量上限 | 128 | `MaxEnvironmentVariables` |
| 标准输入上限 | 1 MB (1,048,576) | `MaxInputBytes` |
| 单流输出上限 | 1 MB (1,048,576) | `MaxOutputBytesPerStream` |
| 总输出上限 | 1 MB (1,048,576) | `MaxTotalOutputBytes` |

### 6.3 文件工具 (`fs.*`)

| 限制 | 值 | 说明 |
| --- | --- | --- |
| 最大递归深度 | 32 | `maxDepth` 参数范围 0–32 |
| 最大扫描文件数 | 10,000 | `MaxSearchFiles`，目录遍历条目上限 |
| 最大搜索结果数 | 100 | `MaxSearchResults`，内容搜索命中上限 |
| 最大编辑操作数 | 100 | 单次 `fs.edit` 调用中的编辑操作条目数。无命名常量，源码中为硬编码字面量（`operations.Length is < 1 or > 100`） |
| 最大传输文件大小 | 64 MB (67,108,864) | `MaxTransferFileSizeBytes` |

### 6.4 Skills 系统

| 限制 | 值 | 说明 |
| --- | --- | --- |
| 目录最大 Skill 数 | 512 | `MaxCatalogSkills` |
| 单 Skill 最大文件数 | 256 | `MaxSkillFiles` |
| SKILL.md 最大体积 | 1 MB (1,048,576) | `MaxSkillDefinitionBytes` |
| 单文件最大体积 | 8 MB (8,388,608) | `MaxSkillFileBytes` |
| Skill 总体积上限 | 16 MB (16,777,216) | `MaxSkillTotalBytes` |
