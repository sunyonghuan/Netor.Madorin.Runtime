# Madorin CLI 概念与导航

> 适用版本：Madorin.AI.Runtime V1，协议 1.1，SQLite Schema 16
>
> 本文是《使用指南》的入口。先读本文建立概念，再按场景进入后续文档。所有命令都通过 Runtime 服务执行，不要手工修改 `.madorin` 内部文件。

## 1. madorin 是什么

madorin 是一个可独立安装、独立运行、独立升级的 AI Runtime，通过一个命令行程序 `madorin` 对外提供入口。它不是“运行一次、打印文本后退出”的传统命令行工具，而是“带 CLI 入口的常驻 AI Runtime”。

Runtime 负责模型访问、内容处理、Agent 执行、流式解析，以及对话历史和可恢复执行状态的权威持久化。CLI 只是它的一个调用入口；宿主程序是另一个调用入口。

## 2. 三种使用场景

同一个 `madorin` 二进制覆盖三种场景，命令集互相独立、语义一致：

| 场景 | 入口 | 典型使用者 |
| --- | --- | --- |
| 独立运行 | 直接执行 `madorin`、`madorin run` | 个人用户、自动化脚本、无宿主调试 |
| 宿主集成 | `madorin serve` + Client SDK 连接 | 桌面/服务宿主程序 |
| 交互式会话 | `madorin` 或 `madorin run`（无 `--input`）进入单行 REPL | 个人用户逐轮对话 |

- 独立运行与交互式会话使用个人配置（`~/.madorin/`）。
- 宿主集成不读取个人配置，配置、凭据和选择由宿主通过 Client SDK 提供。

## 3. 核心概念

理解以下概念后，后续文档中的命令和参数都能对号入座。

| 概念 | 含义 | 稳定标识 |
| --- | --- | --- |
| Workspace（工作区） | 一次执行绑定的项目根目录，是权限和数据的基准 | 规范化路径派生的 `workspaceKey` |
| Session（会话） | 用户可见的连续对话及其规范化历史 | `sessionId` |
| Run / Turn | Session 内的一次流式执行；Run 结束不代表对话结束 | `runId` |
| Selection（选择） | 下一轮使用的 Provider、模型、Agent 和参数 | `selectionVersion` |
| Mode（模式） | Session 的运行形态：expert / meeting / work | 创建后不可隐式改变 |
| `.madorin` | 工作区内的 Runtime 保留数据区 | 见第 5 节 |

关键不变式：切换 Provider、模型、Agent 或提示词只影响**下一轮**，不改变 `sessionId`，不清空历史，不新建会话。

## 4. 三种运行模式

模式在创建 Session 时确定，V1 内不可隐式改变。独立 CLI 用 `--mode` 选择；三种模式共用同一个 `run` 入口。

| 模式 | 语义 | 独立 CLI 下的 Agent 集合 |
| --- | --- | --- |
| expert（默认） | 单个 Agent 按 Session 连续执行多轮 | 使用当前选定的单个 Agent |
| meeting | 多个 Agent 作为参会者，由主持人调度发言 | 把所有已配置 Agent 作为参与者 |
| work | 总经理 Agent 带领可用子智能体完成任务 | 选定 Agent 作总经理，其余作可用子智能体 |

独立 CLI 下 meeting 和 work 的 Agent 集合**从个人配置自动派生**，不接受 `--participants` 之类的显式集合参数。需要精细控制参与者、总经理和策略时，由宿主通过 Client SDK 传入完整的模式配置。

## 5. `.madorin` 数据区

未显式指定数据目录时，Runtime 使用 `<workspace>/.madorin/`。它是 Runtime 保留区，AI 文件工具、宿主和普通流程都不得直接改动其中内容。

```text
<workspace>/.madorin/
├── state.db          SQLite + WAL：元数据、状态、索引（不存消息正文）
├── messages/
│   ├── <sessionId>.jsonl          CanonicalHistory 消息正文，append-only
│   └── <sessionId>.compact.json   ContextProjection 缓存，可重建
├── blobs/            大型二进制内容，按 sha256 前缀分片
├── checkpoints/      恢复快照
├── staging/          未完成传输，校验后原子发布
├── locks/            工作区写实例锁
└── logs/             诊断日志，非对话权威来源
```

三类数据不能互相替代：`messages/*.jsonl` 是权威正文，`state.db` 是状态与索引，`*.compact.json` 是可重建投影缓存。个人 CLI 文件另在用户主目录 `~/.madorin/`（`config.json`、`agents/`、全局 `memory.md`），详见《02-安装与初始化》。
