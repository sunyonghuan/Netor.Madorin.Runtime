# Madorin Runtime 宿主集成指南

> 适用版本：Madorin.AI.Runtime Client/Contracts **0.1.26+**，协议 1.1
>
> 前置阅读：[01-概念与导航](./01-概念与导航.md)。本文面向用 Client SDK 集成 Runtime 的宿主开发者；编程示例用 C#。

## 0. serve 与连接的两种关系

宿主要么连接一个已在运行的 Runtime，要么让 SDK 自己拉起一个。对应两条路径：

- **独立运行 serve**：由服务管理器或运维手工启动常驻 Runtime。宿主用 `StartPolicy = AttachExisting` 连接。

  ```text
  madorin serve --workspace <path>
    --data-dir <path>        覆盖默认数据目录（默认 <workspace>/.madorin）
    --config-dir <path>      配置目录（默认 <data-dir>/config）
    --log-dir <path>         日志目录（默认 <data-dir>/logs）
    --instance <id>          Runtime 实例名（默认自动生成）
    --pipe-prefix <prefix>   Named Pipe 前缀（默认 madorin.ai.runtime）
    --max-runs <n>           最大并发 Run（默认 4）
  ```

  `serve` 全生命周期持有工作区写锁；缺 `--workspace` 返回退出码 2。运维视角的锁、停机与升级见 [05-安全与数据运维](./05-安全与数据运维.md)。

- **SDK 拉起进程**：宿主用 `StartIfMissing` 或 `AlwaysStart`，由 SDK 通过 `RuntimeExecutablePath` 启动进程。此时不要手工先跑 `serve`。

无论哪条路径，握手 secret 都通过重定向 stdin 传递，不进入命令行、环境变量或实例文件。

## 1. 依赖边界

宿主项目只引用 `Madorin.AI.Runtime.Client` 和必要的 `Madorin.AI.Runtime.Contracts`。不要引用 Provider 实现、MAF、MEAI、SQLite、Persistence 或 Server 项目，也不要解析 Named Pipe 帧、扫描 Runtime 数据目录或访问内部 DI。

一个宿主进程可以持有多个 `RuntimeClient`，每个句柄固定绑定一个 Runtime 实例。查询、取消、事件游标和回调必须以该绑定为边界，不能只按 `runId` 在多个实例之间查找。

## 2. 启动策略

| 策略 | 行为 | 适用场景 |
| --- | --- | --- |
| `AttachExisting` | 只连接现有 Runtime，目标不存在时失败 | Runtime 由服务管理器或其他进程拥有 |
| `StartIfMissing` | 优先连接，连接失败时启动新 Runtime | 单实例桌面宿主 |
| `AlwaysStart` | 始终启动新的独立 Runtime | 多工作区、测试和强隔离宿主 |

启动新进程时 SDK 使用 `ProcessStartInfo.ArgumentList` 传递路径与标识，并通过重定向 stdin 传递随机握手 secret。宿主不要把 secret 放入命令行、环境变量、日志或异常消息。

## 3. 创建 Client

```csharp
using Madorin.AI.Runtime.Client;

var options = new RuntimeClientOptions(
    PipeName: "owned-by-create",
    HostInstanceId: Guid.NewGuid().ToString("N"))
{
    RuntimeExecutablePath = @"C:\Program Files\Madorin\madorin-cli.exe",
    WorkspaceDirectory = @"E:\Projects\demo",
    DataDirectory = @"E:\Projects\demo\.madorin",
    LogDirectory = @"E:\Projects\demo\.madorin\logs",
    RuntimeInstanceId = Guid.NewGuid().ToString("N"),
    PipePrefix = "madorin.ai.runtime",
    StartPolicy = RuntimeStartPolicy.AlwaysStart,
    OwnedProcessClosePolicy = OwnedProcessClosePolicy.Shutdown,
    StartupTimeout = TimeSpan.FromSeconds(15)
};

await using var client = await RuntimeClient.CreateAsync(options, cancellationToken);
var binding = client.InstanceBinding;
```

`InstanceBinding` 只在认证、初始化、能力和版本检查完成后可用，公开：

- `HostInstanceId` 和 `RuntimeInstanceId`
- 规范化工作区
- Runtime PID
- 控制与事件端点
- 当前 Client 是否拥有 Runtime 进程

`ExpectedRuntimeVersion`、`ExpectedRuntimeInstanceId` 和 `ExpectedServerProcessId` 可用于加强连接校验。启动或连接失败通过稳定的 `RuntimeClientException` 派生类型报告。

Client 还公开只读 `State` 和 `Completion`。`Completion` 在正常 `DisposeAsync` 后成功完成；心跳不可恢复故障或 Client 自己拥有的 Runtime 进程退出时以首次故障完成。`RuntimeProcessExitedException` 仅用于 owned process，并包含 `ProcessId`、`ExitCode`、`ExitedAt` 和最后确认的 GSN；`AttachExisting` 不伪造退出码，只报告连接异常。

## 4. 启动 Run 与处理事件

新建和继续 Session 分别使用 `NewSessionRunRequest` 与 `ExistingSessionRunRequest`：

```csharp
var runId = await client.StartNewSessionRunAsync(request, cancellationToken);

await foreach (var item in client.ReadEventsAsync(lastConfirmedGsn, cancellationToken))
{
    await durableProjection.ApplyAsync(item, cancellationToken);
    await client.AcknowledgeEventsAsync(item.Gsn, cancellationToken);
}
```

事件显式携带 `runtimeInstanceId`、`runId`、GSN 和 Run 内序号。只有业务投影或其他持久化处理成功后才能调用 `AcknowledgeEventsAsync`；提前确认会让重连后无法重放尚未处理的事件。

`RunQueryResult`、`RunListItem` 和 `RunStatusChangedEvent` 的追加字段用于宿主状态投影：`Mode`、固定词汇的 `Phase`、`CurrentStep`、`CompletedUnits`、`TotalUnits`、`UpdatedAt`、`LastRunSequence`（查询项）和脱敏 `Error`。计数非负且同时存在时已完成数不大于总数；文本 Delta 不写入进度列。旧 Runtime 缺少这些字段时按 `null`/`0` 处理。

每个 Runtime 单独保存 `(runtimeInstanceId, lastConfirmedGsn)`。即使多个实例故意产生相同 `runId` 和相同数值 GSN，也不得合并游标或路由表。

## 5. 宿主回调

```csharp
var callbacks = new RuntimeHostCallbacks
{
    ToolPermissionRequestedAsync = HandlePermissionAsync,
    ApprovalRequestedAsync = HandleApprovalAsync,
    ToolCallRequestedAsync = ExecuteToolAsync,
    ToolResultQueriedAsync = QueryToolResultAsync,
    ToolCallCancelledAsync = CancelToolAsync,
    MaxConcurrency = 4,
    CallbackTimeout = TimeSpan.FromSeconds(30)
};
```

把 `callbacks` 传给 `RuntimeClientOptions.HostCallbacks`。SDK 对回调统一施加有界并发、排队/执行超时和取消映射；单个回调异常会转换为协议错误响应，不会终止事件循环。

工具目录通过 `ReplaceToolCatalogAsync` 或 `PatchToolCatalogAsync` 发布。具有副作用的工具调用按稳定 `callId` 幂等；重连或超时后用 `ToolResultQueriedAsync` 查询持久化结果，不能直接再次执行副作用。权限与审批响应必须保留 Runtime、Run、Agent、Grant 和委派归属。

## 6. Session 与 Selection

Client 高层 API 覆盖：

- `ListSessionsAsync`、`GetSessionAsync`、`ListSessionMessagesAsync`
- `UpdateSessionSelectionAsync`
- `ResumeSessionAsync`、`RehydrateSessionAsync`
- `QueryRunAsync`、`ListRunsAsync`、`CancelRunAsync`
- `ReplaceToolCatalogAsync`、`PatchToolCatalogAsync`、`RevokeGrantAsync`
- `UpdateCredentialsAsync`

Selection 更新只影响下一轮，不改变 `sessionId` 或清空历史。继续对话使用 `ExistingSessionRunRequest`；Runtime 重启后先 rehydrate，再从已确认 GSN 继续事件流。

## 7. 重连与恢复

SDK 在当前 Client 绑定内管理控制/事件通道重连，不会切换到其他 Runtime。宿主仍需持久化：

```text
runtimeInstanceId
lastConfirmedGsn
sessionId
runId
业务任务与 Runtime Run 的映射
```

恢复顺序：

1. 使用原实例信息重新连接，校验 PID、认证、Runtime 实例、协议和能力。
2. 从持久化的 `lastConfirmedGsn` 调用 `ReadEventsAsync`。
3. 对至少送达一次的事件按 `(runtimeInstanceId, gsn)` 去重。
4. 业务处理成功后再推进确认水位。
5. 查询 Run 终态；Runtime 已重启时按 Session 执行 rehydrate/resume。

断线期间不要仅凭本地超时把 Run 判为失败，也不要因重放重复执行工具副作用。

## 8. 生命周期与关闭

`DisposeAsync` 只停止当前句柄的后台循环和连接。`AttachExisting` 连接的进程不归 Client 所有；Client 启动的进程按 `OwnedProcessClosePolicy` 处理：

- `KeepAlive`：释放 Client 后保留 Runtime。
- `Shutdown`：先优雅关闭，超过 `OwnedProcessShutdownTimeout` 后只终止该 Client 拥有的进程。

SDK 不枚举、不附着和不终止其他工作区或其他 Client 拥有的 Runtime。

多实例宿主应为每个 Client 独立启动刷新循环和事件消费循环。单个实例的 `Completion` 故障只标记该实例为“等待确认”，保留最后快照并继续刷新其他实例；不得由宿主把未确认的 Run 伪造为业务终态。恢复时先从持久化游标重放事件，再查询原 `runId` 和该 Session 下的非终态 Run 列表。

## 9. 版本升级与回退

1. 停止向旧 Runtime 分配新 Run，等待活动 Run 排空或按业务策略取消。
2. 保留旧二进制和数据恢复点，启动新版本独立实例。
3. 完成 PID、双向认证、协议、能力和 `ExpectedRuntimeVersion` 检查。
4. 对目标 Session 执行 rehydrate，并从旧实例最终确认游标之后建立新实例自己的游标。
5. 冒烟验证新 Run、工具回调、取消和事件确认后再切换业务流量。
6. 失败时关闭新实例并恢复旧版本；不要让两个版本同时写同一规范化工作区。

数据库迁移只允许向前执行。升级前先运行 `madorin db check`、`madorin db backup` 和 `madorin db migrate --dry-run`；不要把复制活动 `state.db` 当作在线备份。数据维护命令的锁与恢复点语义见 [05-安全与数据运维](./05-安全与数据运维.md)。

完整的三 Runtime 集成示例位于 `Madorin.AI.Runtime.SampleHost` 的 `reference-host` 入口。

## 10. 宿主模式配置注入（必读）

独立 CLI（`madorin run` / REPL）读 `~/.madorin/config.json`。**宿主模式（`serve` + Client SDK）不读个人配置**，也不读宿主 SQLite / 系统设置。执行所需内容必须由宿主经协议 **by-value** 传入。

设计背景与硬规则见 Ai.Runtime 方案设计 [08-宿主模式配置注入与Selection颗粒度](../方案设计/08-宿主模式配置注入与Selection颗粒度.md)。本节给出**宿主侧可执行接入**。

### 10.1 颗粒度与对象映射

| 宿主对象 | Runtime 对象 | 配置含义 |
| --- | --- | --- |
| Project | 无直接对象 | **不**承载执行 Selection |
| 项目根目录 | Workspace / 通常一个 `serve` 实例 | 进程与数据区；Client 按 Workspace 缓存 |
| WorkSession（任务页 / 标签） | Runtime Session | Mode 创建锁定；默认 Selection 可更新 |
| 一次发送 | Runtime Run | 本轮冻结的 Selection + 已解析 Provider |
| 系统设置 Vendor/Model/Agent/Credential | 无表 | 宿主组装后注入 |

四层：

1. **材料层（仅宿主）**：Vendor / Credential / Model / Agent 目录。  
2. **会话层**：Mode（创建锁定）+ 默认 `NextTurnSelection` + 首次 `ProviderConfigs`。  
3. **轮次层**：每个 Run 启动时冻结；UI 切换只写 pending，下一轮再生效。  
4. **进程层**：`HostProviderRegistry` 按 `ProviderId` 缓存；重启后须重注。

`ProviderId` 是 Registry 主键，**概念上不等于**宿主 `VendorId`。单密钥时字符串可相同；多 credential/profile 必须派生不同 `ProviderId`，否则后写覆盖前写。

### 10.2 宿主发送前必须组装的载荷

#### `HostProviderConfig`（厂商连接，明文仅管道内存）

| 字段 | 要求 |
| --- | --- |
| `ProviderId` | 必填；trim 后非空 |
| `Protocol` | 必填；须为 Runtime 已识别协议（如 `OpenAI`、`DeepSeek`、`Anthropic`、`OpenAI Compatible`…） |
| `BaseUrl` | 必填 |
| `ApiKey` | 必填（解密明文）；不得写入 selection 落盘 |
| `AuthenticationHeader` / `AuthenticationScheme` / `UserAgent` / `ApiVersion` / `Models` / `ConfigurationVersion` | 可选 |

不纳入宿主配置：独立探测用的 `Capabilities` / `ProbePath` / `MaxTools`。

#### `AgentRef`（智能体快照，禁止只传 ID）

| 字段 | 要求 |
| --- | --- |
| `AgentId` | 必填 |
| `PromptTemplateVersion` | 必填（如 `"1"`） |
| `SystemPrompt` | **必填非空**；编排直接使用 |
| `ProviderId` / `ModelId` | 可选；主 Agent 有值时须与 `DefaultSelection` 对应字段相等 |
| `AllowedToolIds` / `SkillIds` | 可选；`null`=未声明，`[]`=显式无 |

#### `NextTurnSelection`

- `SelectionVersion`、`Mode`（须与请求顶层 `Mode` 一致）  
- `DefaultSelection`：`ProviderId` + `ModelId`（均非空）——本轮主执行选型权威  
- `ModeOptions`：  
  - Expert → `ExpertModeOptions(Agent)`  
  - Work → `WorkModeOptions(GM, AvailableAgents[])`，`AvailableAgents` 至少 1 项且每项完整  
  - Meeting → `MeetingModeOptions(Participants...)`，Participants 至少 1 且 Agent 完整  

### 10.3 请求挂载点

| 请求 | 字段 | 何时带 |
| --- | --- | --- |
| `run.new_session` / `NewSessionRunRequest` | `ProviderConfigs?` | **首轮主路径应带**本会话用到的厂商；空且 Registry 无项 → `ProviderNotConfigured` |
| `run.existing_session` / `ExistingSessionRunRequest` | `ProviderConfigs?` | 下一轮换了尚未注册的 `ProviderId` |
| `session.selection.update` | `ProviderConfigs?` | 更新默认 Selection 时补注册 |
| `providers.upsert` | `Providers[]` | 可选预热；非必须 |
| `credentials.update` | Run 绑定 | 仅 API Key 轮换；**不能**代替创建时注入 |

### 10.4 端到端时序（Expert 示例）

```text
1. 宿主激活项目 → RuntimeClient.CreateAsync（StartIfMissing/AlwaysStart）
   → madorin-cli serve --workspace ... （Registry 初始为空）

2. 用户在任务会话首次发送
   材料库 → 解密 Key → HostProviderConfig
   Agent 定义 → 完整 AgentRef（含 SystemPrompt）
   组装 NextTurnSelection + InitialInput
   → StartNewSessionRunAsync(NewSessionRunRequest { ProviderConfigs, Selection, ... })

3. Runtime：Upsert Registry → 宿主校验 → CreateSession → Run
   → 事件：run.accepted / output.delta / run.completed|failed|cancelled

4. 同会话再发（无切换）
   → StartExistingSessionRunAsync(SessionId, InputOverride)
   可不带 TurnOverride / ProviderConfigs

5. 对话中 UI 改厂商/模型/智能体
   Run 进行中：只写宿主 pending，不中断当前 Run，不热改本轮
   Run 终态后再发：TurnOverride = 新完整 Selection
                 + 新厂商则附 ProviderConfigs
```

换 **Mode** 必须新 WorkSession + 新 `run.new_session`，不能在同 Session 内改 Mode。

### 10.5 C# 最小完整示例（宿主模式）

```csharp
using Madorin.AI.Runtime.Client;
using Madorin.AI.Runtime.Contracts;
using Madorin.AI.Runtime.Entities;

// 1) 拉起 / 连接 serve（宿主模式：不传个人 config）
await using var client = await RuntimeClient.CreateAsync(new RuntimeClientOptions(
    PipeName: "owned-by-create",
    HostInstanceId: Guid.NewGuid().ToString("N"))
{
    RuntimeExecutablePath = @"...\madorin-cli.exe",
    WorkspaceDirectory = workspaceRoot,
    DataDirectory = Path.Combine(workspaceRoot, ".madorin"),
    RuntimeInstanceId = Guid.NewGuid().ToString("N"),
    StartPolicy = RuntimeStartPolicy.AlwaysStart,
    OwnedProcessClosePolicy = OwnedProcessClosePolicy.Shutdown,
}, ct);

const string providerId = "deepseek-main"; // 可由 VendorId 派生
var provider = new HostProviderConfig(
    ProviderId: providerId,
    Protocol: "DeepSeek",                 // 须与协议目录一致（大小写敏感）
    BaseUrl: "https://api.deepseek.com",
    ApiKey: decryptedApiKey,              // 宿主解密后的明文
    Models: ["deepseek-v4-flash"]);

var agent = new AgentRef(
    AgentId: "default-expert",
    PromptTemplateVersion: "1",
    SystemPrompt: "你是项目助手。用中文简洁回答，需要落盘时说明文件名。",
    ProviderId: providerId,               // 可省略；给出则必须等于 DefaultSelection
    ModelId: "deepseek-v4-flash");

var selection = new NextTurnSelection(
    SelectionVersion: 1,
    Mode: RuntimeMode.Expert,
    DefaultSelection: new DefaultSelection(providerId, "deepseek-v4-flash"),
    ModeOptions: new ExpertModeOptions(agent));

// 2) 首轮：ProviderConfigs + 完整 AgentRef
var runId = await client.StartNewSessionRunAsync(
    new NewSessionRunRequest(
        SessionIdempotencyKey: Guid.NewGuid().ToString("N"),
        RunIdempotencyKey: Guid.NewGuid().ToString("N"),
        Mode: RuntimeMode.Expert,
        Selection: selection,
        InitialInput: [new TextContentBlock("请写一份一页的 README 大纲。")],
        ProviderConfigs: [provider]),
    ct);

long cursor = 0;
await foreach (var ev in client.ReadEventsAsync(cursor, ct))
{
    // 处理 output.delta / run.completed 等
    await client.AcknowledgeEventsAsync(ev.Gsn, ct);
    cursor = ev.Gsn;
    if (ev.MessageType is MessageTypes.RunCompleted
        or MessageTypes.RunFailed
        or MessageTypes.RunCancelled)
        break;
}

// 3) 同会话下一轮（无切换）
var sessionId = (await client.QueryRunAsync(runId, ct)).SessionId;
await client.StartExistingSessionRunAsync(
    new ExistingSessionRunRequest(
        sessionId,
        Guid.NewGuid().ToString("N"),
        InputOverride: [new TextContentBlock("把大纲扩成三级标题。")]),
    ct);

// 4) 可选：实例预热
// await client.UpsertProvidersAsync([provider], ct);

// 5) 401/403 时：事件 credentials.refresh.request → UpdateCredentialsAsync
```

### 10.6 校验失败时宿主应如何处理

失败默认 = **拒绝整请求**（不创建 Session / 不启动本 Run），错误经 JSON-RPC 返回。常见原因：

| 现象 | 原因 | 宿主动作 |
| --- | --- | --- |
| Provider not configured | 未带 `ProviderConfigs` 且 Registry 无该 Id | 补传 `HostProviderConfig` 后重试 |
| SystemPrompt / Agent 不完整 | 只传了 ID 或空提示词 | 物化完整 `AgentRef` |
| must equal DefaultSelection | 主 Agent 的 Provider/Model 与默认不一致 | 对齐或省略 Agent 侧字段 |
| Mode mismatch | 顶层 Mode ≠ Selection.Mode 或 ModeOptions 类型不对 | 修正双写 |
| Work AvailableAgents 空 | 子 Agent 列表 null/`[]` | 至少 1 个完整 child |
| Protocol unsupported | 协议名不在目录（注意 `DeepSeek` 不是 `Deepseek`） | 使用目录标准名 |

### 10.7 明确禁止

- 只传 VendorId/ModelId，期望 CLI 反查宿主库或 `~/.madorin/config.json`  
- 当前 Run 执行中热替换 Selection / SystemPrompt  
- 用 `credentials.update` 代替创建时 Provider 注入  
- 多密钥共用同一 `ProviderId`  
- 向 Runtime 提交空 `SystemPrompt` 的 AgentRef  
- 把 ApiKey 写入 selection JSON 或业务落盘明文  

### 10.8 Workstation（本仓）落地清单

| 步骤 | 位置建议 | 说明 |
| --- | --- | --- |
| 材料库读 Vendor/Model/Agent/Credential | F09 / Services | 解密 Key 仅内存 |
| 派生 `ProviderId` | Gateway 组装 | 单密钥可 = VendorId 字符串 |
| 物化 `AgentRef` | Gateway | SystemPrompt、tools/skills、版本 |
| 组装 `NewSessionRunRequest` | F06 Runtime Gateway | 带 `ProviderConfigs` |
| pending Selection | F04 WorkSession 状态 | 活跃 Run 期间不发 TurnOverride |
| 事件消费 | F06 | `output.delta`、`run.*`、`credentials.refresh.request` |
| Client 可执行路径 | 发布/安装 | 使用发布产物 `releases/Madorin-Cli/madorin-cli/bin/madorin-cli.exe`（当前 0.1.26） |
