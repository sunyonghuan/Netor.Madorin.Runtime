## 冻结契约

公共 record 保留现有主构造函数，新增可空 `init` 属性：

- `RunQueryResult`、`RunListItem`：`Mode`、`Phase`、`CurrentStep`、`CompletedUnits`、`TotalUnits`、`UpdatedAt`、`LastRunSequence`、`Error`。
- `RunStatusChangedEvent`：除 `LastRunSequence` 外新增同一进度字段；事件顺序仍取 Envelope.RunSequence。
- `IRuntimeClient`：只读 `RuntimeClientState State` 与 `Task Completion`。
- 新增 `RuntimeProcessExitedException`，仅 owned process 确认退出时报告退出码；attach 只报告连接异常。

Phase 固定为 `preparing`、`running`、`waiting-for-tool`、`waiting-for-approval`、`waiting-for-credentials`、`persisting`、`terminal`。计数非负，二者同时存在时 `CompletedUnits <= TotalUnits`。旧 JSON 缺失新增字段反序列化为 `null`/`0`；未知新增字段可忽略；GSN、ACK 和终态语义不变。
