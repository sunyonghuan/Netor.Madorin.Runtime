# Madorin CLI 命令行与交互使用

> 适用版本：Madorin.AI.Runtime V1，协议 1.1，SQLite Schema 14
>
> 前置阅读：[01-概念与导航](./01-概念与导航.md)、[02-安装与初始化](./02-安装与初始化.md)。
>
> 命令的完整契约以 [命令规范/09-CLI命令矩阵](../命令规范/09-CLI命令矩阵.md) 为准，本文只讲用法。

## 1. 单次运行

最小单次执行：给一个工作区和一段输入，执行后退出。

```text
madorin run --workspace <path> --input "检查当前任务并给出下一步"
```

从文件读取长输入，并生成可脚本解析的结果：

```text
madorin run --workspace <path> --input-file ./request.md --mode expert --output-format json --output-file ./result.json --no-stream
```

要点：

- `--input` 与 `--input-file` 互斥，二者只能给一个。
- `--session <sessionId>` 继续已有会话；不给则新建会话。
- `--mode` 取 `expert`（默认）、`meeting`、`work`，见第 4 节。
- `--output-format` 取 `text`（默认）、`json`、`jsonl`；`--no-stream` 等待完整结果再输出。
- JSON/JSONL 模式下 stdout 只含机器数据，进度和诊断写 stderr；输出文件用同目录临时文件原子发布，失败时保留已有有效结果。
- JSON 消费方式见 [06-自动化与故障排查](./06-自动化与故障排查.md)。

### 1.1 工作区初始选择

`run --workspace <path>` 和裸启动都会在启动时读取 `<path>/.madorin/config.json`。该文件只影响初始 Agent、Provider 和 Model，不改变全局 Provider/Agent 目录，也不会在 REPL 中热更新。

Agent 按“`--agent` > 工作区 > 全局”选择；Provider/Model 按“命令行参数 > Agent 绑定 > 工作区 > 全局”逐字段选择。`/provider`、`/model`、`/agent` 和 `/new` 只修改当前进程的后续选择，不重新读取或写回配置文件。

使用以下命令查看每个最终值来自 `commandLine`、`agent`、`workspace` 还是 `global`：

```text
madorin config show --workspace <path>
```

## 2. 单行 REPL

在目标工作区目录下直接运行 `madorin`（或 `madorin run` 不带 `--input`）进入单行 REPL：

```text
madorin
```

REPL 逐轮接收输入并执行一个 Run。Run 执行期间 CLI 不并发读取下一条输入；多行内容通过 `--input-file` 以单次运行方式提交。

### 2.1 中断行为（两阶段）

1. Run 执行中第一次 Ctrl+C 只取消当前 Run。
2. CLI 等待该 Run 收敛为唯一 `Cancelled` 终态，然后返回提示符。
3. 用户可以在同一 Session 中修改要求并继续输入。
4. 取消收敛期间再次 Ctrl+C，或空闲时 Ctrl+C，退出 CLI 并返回退出码 130。

EOF 也会结束 REPL。
## 3. 斜杠命令

REPL 内以 `/` 开头的命令控制当前会话，不发送给模型。

选择类（只更新下一轮 Selection，不改变 `sessionId`、不清空历史）：

| 命令 | 作用 |
| --- | --- |
| `/model [modelId]` | 查看或切换下一轮模型 |
| `/provider [providerId]` | 查看或切换下一轮 Provider |
| `/agent [agentId]` | 查看或切换下一轮 Agent |
| `/mode` | 只显示当前模式；模式在 Session 内不可改 |

会话类：

| 命令 | 作用 |
| --- | --- |
| `/session` | 显示当前会话信息（sessionId、模式、消息数、Provider） |
| `/new` | 下一轮开始新会话（当前会话保存并关闭） |
| `/resume [sessionId]` | 切换到指定会话；无参数时列出可恢复会话 |
| `/history [n\|all]` | 显示最近 n 条消息（默认少量）；`all` 显示全部 |
| `/export [path]` | 把当前会话导出为 Markdown；无参数输出到 stdout |

上下文与工具类：

| 命令 | 作用 |
| --- | --- |
| `/compact` | 立即为当前会话触发上下文压缩，显示前后 token 估算 |
| `/context` | 显示 CanonicalHistory 与 ContextProjection 的消息数与 token 估算 |
| `/tools` | 显示当前 Run 可用工具及权限状态 |

记忆类：

| 命令 | 作用 |
| --- | --- |
| `/memory [global\|project\|effective]` | 显示记忆内容与来源 |
| `/remember <global\|project>` | 追加一条记忆，需交互审批 |

其他：

| 命令 | 作用 |
| --- | --- |
| `/status` | 显示 Runtime 当前状态（工作区、活动、内存、工具计数） |
| `/clear` | 清除终端显示，不清除历史记录 |
| `/help [command]` | 显示命令列表或某命令详细说明 |
| `/exit` / `/quit` | 保存会话并退出 |

`/model`、`/provider`、`/agent` 只影响下一轮：当前流正常结束后，下一轮在原 Session、原历史上重建执行 Agent 并立即生效。
## 4. 三种运行模式

模式在创建 Session 时用 `--mode` 确定，V1 内不可隐式改变；`/mode` 只显示不修改。切换到别的模式属于显式新建会话。

```text
madorin run --workspace <path> --mode expert  --input "..."
madorin run --workspace <path> --mode meeting --input "..."
madorin run --workspace <path> --mode work    --input "..."
```

三种模式在独立 CLI 下的 Agent 集合**从个人配置自动派生**：

| 模式 | 语义 | 集合来源 |
| --- | --- | --- |
| expert | 单 Agent 连续多轮 | 当前选定的单个 Agent |
| meeting | 多 Agent 参会、主持人调度发言 | 所有已配置 Agent 作为参与者，按配置顺序确定入场序 |
| work | 总经理带子智能体完成任务 | 选定 Agent 作总经理，其余作可用子智能体 |

独立 CLI 不接受显式的参与者/子智能体集合参数。要精细控制参与者名单、总经理、发言策略和工作流策略，由宿主通过 Client SDK 传入完整模式配置（见 [04-宿主集成指南](./04-宿主集成指南.md)）。因此 meeting / work 想得到有意义的结果，需先在配置中准备足够的 Agent。

## 5. 会话管理

`session` 命令组管理已持久化的会话，多数是只读的，指定工作区即可离线操作，不需要连接运行中的 Runtime。

### 5.1 列表与查看

```text
madorin session list --workspace <path> --status active --limit 20
madorin session show <sessionId> --workspace <path> --messages
```

`session list` 支持 `--status`（`active` 默认 / `archived` / `all`）、`--mode`、`--since <ISO8601>`、`--search <关键字>`、`--limit`（1–200，默认 20）、`--cursor`（游标分页）。`session show` 加 `--messages` 附带每条消息的元数据。

### 5.2 导出

```text
madorin session export <sessionId> --workspace <path> --format markdown --output ./s1.md
```

`--format` 取 `markdown`（默认）、`txt`、`jsonl`；不给 `--output` 时打印到 stdout。默认不含推理过程和工具调用，加 `--include-reasoning`、`--include-tool-calls` 才包含。导出文件用原子替换写入。
### 5.3 归档

归档只是把会话从活动列表隐藏，不删除数据；可随时恢复。

```text
madorin session archive <sessionId> --workspace <path>
madorin session unarchive <sessionId> --workspace <path>
```

### 5.4 压缩

手动为指定会话触发上下文压缩，生成摘要并刷新 `.compact.json`。

```text
madorin session compact <sessionId> --workspace <path> --dry-run
madorin session compact <sessionId> --workspace <path> --strategy summary
```

`--strategy` 取 `full`、`sliding-window`、`summary`（默认）。`--dry-run` 只显示压缩计划；`--force` 即使现有缓存仍有效也强制重建；`--keep-last-tokens` 控制保留的近端窗口；`--provider`/`--model` 覆盖生成摘要所用的模型。压缩只改可重建的投影缓存，不改权威 `.jsonl` 正文。

### 5.5 删除

```text
madorin session delete <sessionId> --workspace <path> --confirm
```

`delete` 必须显式 `--confirm`，否则返回退出码 2。默认只删除 `state.db` 记录和 `.jsonl` 消息文件，**不删除** `blobs/`（Blob 内容寻址、可能被其他会话共享）。要清理孤立 Blob，用 `storage gc`（见 [05-安全与数据运维](./05-安全与数据运维.md)）。加 `--include-blobs` 才一并删除该会话引用的 Blob。
