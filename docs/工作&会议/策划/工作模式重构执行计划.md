# 工作模式重构执行计划

## 一、重构目标

将当前的 Work 模式改造为完整的**三层架构**：

```
总经理（GeneralManager）
├─ 与用户沟通，讨论需求
├─ 制定二级结构化计划
├─ 从 AvailableAgents 中选择合适的 Agent，或创建临时 Agent
├─ 接收项目组长的汇总报告
└─ 生成最终总结报告

项目组长（WorkSupervisor）
├─ 接收确认后的计划
├─ 按一级步骤顺序派发
├─ 每个一级步骤内按二级步骤顺序执行
├─ 验证每个二级步骤的结果
├─ 处理超时、重试、失败
├─ 汇总二级步骤结果到一级步骤
└─ 汇总所有一级步骤结果上报给总经理

工人（Worker Agent）
├─ 接收二级步骤指令
├─ 执行具体工作
└─ 返回执行结果
```

---

## 二、当前架构分析

### 2.1 已实现的功能 ✅

1. **总经理角色**：`WorkModeOptions.GeneralManager`
2. **可用 Agent 清单**：`WorkModeOptions.AvailableAgents`
3. **执行器循环**：`WorkModeOrchestrator.RunCoreAsync` 的 `while (true)` 循环
4. **超时重试**：`WorkflowPolicy.StepTimeoutSeconds` + `MaxRetriesPerStep`
5. **失败策略**：`WorkStepFailurePolicy` (Stop/Continue/Retry/AskHost)
6. **Agent 派发**：`ExecuteInvocationAsync` + `CreateInvocationRequestAsync`

### 2.2 缺失的功能 ❌

1. **二级步骤结构**：当前 `WorkPlanStepDraft` 没有 `SubSteps` 字段
2. **结果验证器**：步骤完成后没有验证结果是否符合预期
3. **结果汇总链路**：二级→一级→总经理的汇总逻辑不存在
4. **总经理最终总结**：所有步骤完成后没有回到总经理生成报告
5. **项目组长角色**：验证和汇总逻辑混在执行器中，没有明确的"组长"概念

```csharp
        string actualOutput,
        string context,
        CancellationToken ct = default);
    
    /// <summary>汇总一级步骤的所有二级步骤结果。</summary>
    Task<string> SummarizeStepResultsAsync(
        WorkPlanStepDraft step,
        WorkSubStepResult[] subStepResults,
        CancellationToken ct = default);
}

public sealed record WorkStepExecutionResult(
```

#### 步骤 2.2：实现 WorkSupervisor

**文件**：`src/Madorin.AI.Runtime.Modes.Work/WorkSupervisor.cs`（新建）

```csharp
namespace Madorin.AI.Runtime.Modes.Work;

/// <summary>项目组长实现：循环执行、验证、汇总。</summary>
public sealed class WorkSupervisor : IWorkSupervisor
{
    private readonly Func<string, IRuntimeProviderAdapter> _providerFactory;
    private readonly AgentRef _supervisorAgent;  // 项目组长的 Agent（用于验证和汇总）
    private readonly WorkflowPolicy _policy;
    
    public WorkSupervisor(
        Func<string, IRuntimeProviderAdapter> providerFactory,
        AgentRef supervisorAgent,
        WorkflowPolicy policy)
    {
        _providerFactory = providerFactory;
        _supervisorAgent = supervisorAgent;
        _policy = policy;
    }
    
    public async Task<WorkStepExecutionResult> ExecuteStepAsync(
        WorkPlanStepDraft step,
        WorkPlanDraft plan,
        CancellationToken ct = default)
    {
        var subStepResults = new List<WorkSubStepResult>();
        
        // 按顺序执行二级步骤
        foreach (var subStep in step.SubSteps)
        {
            var retryCount = 0;
            
            while (retryCount <= _policy.MaxRetriesPerStep)
            {
                // 1. 派发 Worker Agent
                var output = await DispatchWorkerAgentAsync(subStep, ct);
                
                // 2. 验证结果
                var verification = await VerifySubStepAsync(
                    subStep,
                    output,
                    context: BuildVerificationContext(step, subStepResults),
                    ct);
                
                if (verification.Passed)
                {
                    subStepResults.Add(new WorkSubStepResult(
                        subStep.SubStepId,
                        Success: true,
                        Output: output));
                    break;  // 验证通过，跳出重试循环
                }
                
                // 验证失败
                retryCount++;
                if (retryCount > _policy.MaxRetriesPerStep)
                {
                    subStepResults.Add(new WorkSubStepResult(
                        subStep.SubStepId,
                        Success: false,
                        Output: output,
                        ErrorMessage: verification.Reason));
                    
                    // 根据失败策略决定是否继续
                    if (_policy.FailurePolicy == WorkStepFailurePolicy.Stop)
                    {
                        return new WorkStepExecutionResult(
                            Success: false,
                            Summary: $"SubStep '{subStep.SubStepId}' failed after {_policy.MaxRetriesPerStep} retries.",
                            SubStepResults: subStepResults.ToArray());
                    }
                    
                    break;  // Continue 策略：跳过当前二级步骤，继续下一个
                }
                
                // 重试前等待
                await Task.Delay(
                    ComputeRetryDelay(_policy, retryCount),
                    ct);
            }
        }
        
        // 3. 汇总一级步骤结果
        var summary = await SummarizeStepResultsAsync(step, subStepResults.ToArray(), ct);
        
        return new WorkStepExecutionResult(
            Success: subStepResults.All(r => r.Success),
            Summary: summary,
            SubStepResults: subStepResults.ToArray());
    }
    
    public async Task<WorkStepVerificationResult> VerifySubStepAsync(
        WorkPlanSubStepDraft subStep,
        string actualOutput,
        string context,
        CancellationToken ct = default)
    {
        // 调用项目组长 Agent 进行验证
        var prompt = $"""
            你是项目组长，现在要验证二级步骤的执行结果是否符合预期。
            
            步骤目标：{subStep.Goal}
            期望产出：{subStep.ExpectedOutput ?? "未指定"}
            实际产出：{actualOutput}
            上下文：{context}
            
            请判断：
            1. 实际产出是否达到步骤目标？
            2. 实际产出是否与上下文一致？
            3. 如果不符合，是否可以重试？
            
            返回 JSON：
            {{
              "passed": true/false,
              "reason": "通过原因 或 失败原因",
              "retryable": true/false
            }}
            """;
        
        // TODO: 调用大模型执行验证
        // var result = await InvokeSupervisorAgentAsync(prompt, ct);
        
        // 临时实现：简单判断非空
        return new WorkStepVerificationResult(
            Passed: !string.IsNullOrWhiteSpace(actualOutput),
            Reason: string.IsNullOrWhiteSpace(actualOutput) 
                ? "输出为空" 
                : "输出符合预期",
            Retryable: true);
    }
    
    public async Task<string> SummarizeStepResultsAsync(
        WorkPlanStepDraft step,
        WorkSubStepResult[] subStepResults,
        CancellationToken ct = default)
    {
        // 调用项目组长 Agent 进行汇总
        var prompt = $"""
            你是项目组长，现在要汇总一级步骤的所有二级步骤结果。
            
            一级步骤：{step.Title}
            描述：{step.Description}
            
            二级步骤结果：
            {string.Join("\n", subStepResults.Select(r => 
                $"- {r.SubStepId}: {(r.Success ? "成功" : "失败")} - {r.Output}"))}
            
            请生成汇总报告，说明：
            1. 这个一级步骤的整体完成情况
            2. 各二级步骤的关键产出
            3. 是否达到一级步骤的目标
            """;
        
        // TODO: 调用大模型生成汇总
        // var summary = await InvokeSupervisorAgentAsync(prompt, ct);
        
        // 临时实现
        return $"一级步骤 '{step.Title}' 完成：{subStepResults.Count(r => r.Success)}/{subStepResults.Length} 个二级步骤成功。";
    }
    
    private async Task<string> DispatchWorkerAgentAsync(
        WorkPlanSubStepDraft subStep,
        CancellationToken ct)
    {
        // TODO: 调用 Worker Agent 执行二级步骤
        // 复用 WorkModeOrchestrator.ExecuteInvocationAsync 逻辑
        return $"[Worker {subStep.TargetAgentId}] 执行结果";
    }
    
    private static string BuildVerificationContext(
        WorkPlanStepDraft step,
        List<WorkSubStepResult> completedSubSteps)
    {
        return $"一级步骤：{step.Title}\n" +
               $"已完成的二级步骤：\n" +
               string.Join("\n", completedSubSteps.Select(r => 
                   $"- {r.SubStepId}: {r.Output}"));
    }
    
    private static TimeSpan ComputeRetryDelay(WorkflowPolicy policy, int attemptCount)
    {
        if (policy.RetryBackoffMilliseconds <= 0)
            return TimeSpan.Zero;
        
        var exponent = Math.Clamp(attemptCount, 0, 6);
        var milliseconds = Math.Min(
            60_000L,
            (long)policy.RetryBackoffMilliseconds * (1L << exponent));
        return TimeSpan.FromMilliseconds(milliseconds);
    }
}
```

**文件**：`src/Madorin.AI.Runtime.Modes.Work/WorkModeOrchestrator.cs`

```csharp
private async Task<string> GenerateFinalSummaryAsync(
    string sessionId,
    string runId,
    WorkPlanDraft plan,
    IReadOnlyList<WorkStepSnapshot> steps,
    AgentRef generalManager,
    NewSessionRunRequest request,
    CancellationToken ct)
{
    // 构建总经理总结的输入
    var prompt = $"""
        你是总经理，现在要对整个工作计划的执行情况生成最终总结报告。
        
        原始目标：{plan.Goal}
        
        计划版本：{plan.PlanVersion}
        
        执行结果：
        {string.Join("\n\n", steps
            .Where(s => string.IsNullOrEmpty(s.ParentStepId))  // 只列一级步骤
            .Select(s => $"步骤 {s.StepId}：{s.Status}\n{s.ResultJson}"))}
        
        请生成总结报告，包括：
        1. 整体完成情况（成功/失败步骤数量）
        2. 各步骤的关键产出和位置
        3. 是否达到原始目标
        4. 存在的问题和建议
        """;
    
    // 调用总经理 Agent
    var managerInvocation = await CreateInvocationRequestAsync(
        runId,
        sessionId,
        request,
        generalManager,
        "work-summary-v1",
        ct).ConfigureAwait(false);
    
    await AppendPlainDialogueAsync(
        sessionId,
        managerInvocation.InvocationId,
        "runtime",
        "user",
        prompt,
        ct).ConfigureAwait(false);
    
    var summaryBuilder = new StringBuilder();
    await foreach (var providerEvent in ExecuteInvocationAsync(managerInvocation, ct)
        .ConfigureAwait(false))
    {
        if (providerEvent is TextDeltaProviderEvent textDelta)
        {
            summaryBuilder.Append(textDelta.Delta);
        }
    }
    
    return summaryBuilder.ToString();
}
```

## 五、验收标准

1. ✅ 总经理能生成二级结构的计划
2. ✅ WorkSupervisor 能按二级步骤顺序执行
3. ✅ 每个二级步骤完成后自动验证
4. ✅ 验证失败时自动重试
5. ✅ 二级步骤结果汇总到一级步骤
6. ✅ 所有步骤完成后总经理生成最终报告
7. ✅ 超时、失败策略正常工作
8. ✅ 现有的并发执行、依赖调度功能不受影响

## 六、风险和注意事项

1. **破坏性改动**：WorkPlanStepDraft 结构变化，需要更新所有依赖代码
2. **性能影响**：每个二级步骤增加验证调用，会增加总耗时和成本
3. **兼容性**：需要考虑是否支持旧版本的扁平化计划
4. **测试覆盖**：需要补充大量单元测试和集成测试
