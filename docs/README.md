## 2. 当前项目快照

当前项目已经从“总体策划”进入 V1 主闭环实现和验收阶段。仓库根 README 记录的当前工程形态是：

- 解决方案：`Madorin.AI.Runtime.slnx`。
- 技术栈：.NET 10、中央包管理、严格编译、Native AOT 发布配置。
- 工程组成：源码项目、Provider 项目、参考宿主和测试项目共同构成独立 Runtime。
- 入口命令：`madorin`，覆盖 REPL、单次任务、常驻服务、诊断、配置、Agent、记忆、会话、数据库、存储和在线控制。
- Provider 方向：OpenAI、Anthropic、OpenAI Compatible、DeepSeek、Kimi、Aliyun / DashScope、Gemini、GLM、Ollama，以及实验性的 Azure OpenAI。
- 数据层：SQLite + WAL 保存状态和索引，JSONL 保存权威消息正文，Blob Store 保存大型内容。

更详细的构建、运行和项目结构说明，以[仓库根 README](../README.md)为准；本文不重复维护命令示例，避免再次过期。
